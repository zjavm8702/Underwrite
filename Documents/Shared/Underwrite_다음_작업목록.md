## 5-1. 슬롭 점검 결과와 개선 (2026-10-18)

사장님 질문 「UI·캐릭터 그래픽이 슬롭 같아 보이나」에 과장(Claude)과 대리(Codex)가 따로 본 판정. 근거는 Play 캡처 3장(거래 화면, 지하 정보, 영지)과 초상 원본.

**판정**

| 대상 | 과장 | 대리 | 정리 |
|---|---|---|---|
| 초상 | AI 티 확실 — 얼굴 틀 하나, 주민까지 미남미녀, 엘프 노출 클리셰, 자르는 모양·머리 크기 제각각 | 경계선 — 엘프가 아트 규칙(긴 생머리·작은 귀·절제된 채색)에서 벗어남, 요정은 장식이 얼굴을 이김, 중개인·집사는 미남 초상 문법, 놀람 표정이 다 같음 | **둘 다 문제로 봄** |
| UI | 슬롭보다 템플릿 — 거래 화면은 웹 대시보드, 지하 화면과 디자인 언어가 다름 | 경계선 — 금융 대시보드에 양피지를 씌운 인상, 자산 카드와 본문의 위계 없음, 테두리 두께·장식량 기준 없음 | **같은 진단** |
| 영지 | 가장 나음 — 단 소품 반복·바닥 균일·밀도 차 | **슬롭 쪽** — 바닥 대비가 강해 캐릭터를 묻음, `elf_2`·나무·화분 과잉 장식, 수레와 벤치의 묘사 수준 차, 「에셋 전시판」 | **의견이 갈림.** 사장님은 Play 화면에서 괜찮다고 봄. 지적 항목은 둘이 겹친다 |
| 필드 캐릭터 | 초상과 화풍이 다름(셀 애니 vs 반실사) | 노점상은 둥근 동화풍, 집사는 길쭉한 성인 비율, porter 굵은 선 vs leader 섬세한 선, 주인공 SE 걷기 손·소매가 프레임마다 다시 그려짐 | **규격 통일 필요** |

공통 진단: 개별 그림이 망가진 게 아니라 **서로 다른 기준으로 만든 예쁜 에셋을 모아 놓은 인상**(장식 과잉, 비율·선·명암 기준 불일치, 반복 배치).

**원칙:** 초상·UI·캐릭터도 영지처럼 **Play 화면 캡처로 판정**한다. UI는 **이미지 위주**(사장님 입장) — 단 한 벌로 맞춘 키트, 숫자 읽는 칸은 깨끗하게.

**할 일 (공수 작은 순)**

1. **[과장] UI 부품 쓰임 표:** `Assets/UI/Images`의 지금 부품이 어느 화면 어디에 쓰이는지 정리 → 키트 요청 목록
2. **[과장] 영지 배치 정리:** 반복 벤치·화분·가로등·수레를 덜고 장소별 묶음·이동 길을 만든다(`layout.json`). 새 아트 없음
3. **[과장] 영지 시선 정리 시험:** 바닥 대비, 수관 밝기·채도를 조금 낮춰 Play 캡처 전후 비교(주인공이 먼저 읽히는지)
4. **[Codex·승인 후] UI 키트:** 지하 정보창의 금장 양피지 틀을 기준으로 9-slice 틀 3종, 버튼 4상태(기본·강조 매수/매도·탭), 이름판·제목 띠·구분선·밀랍 도장·아이콘 한 벌 → 과장이 거래 화면부터 교체
5. **[Codex·승인 후] 초상 손보기:** 규격(자르는 모양·머리 크기·선 굵기) 통일 → 엘프를 아트 규칙대로 → 주민 다섯 다시(나이·체형·투박함 다양하게, 얼굴 틀 깨기). 지하 「정보상」 두건 초상도 함께
6. **[Codex·승인 후] 필드 캐릭터 마감 기준:** 주인공 기준으로 NPC 머리·몸 비율, 용병단 선 굵기·명암 단계 통일, 주인공 SE 걷기 손·소매 교정
7. **[과장·Codex] 화풍 기준서:** 초상(셀 애니)과 필드(페인팅) 사이를 무엇으로 맞출지 — 아트 규칙 문서에 추가(Codex 소유)

참고: Codex 보고에 「상시 지시서(`Tools/codex-art-brief.md`)의 인간 여성 피봇 표가 최신 아트 규칙(개별 Sprite Rect 중심)과 다르다」는 지적 있음 — 과장이 지시서를 찾아보니 그런 표가 안 보인다. 다른 문서(AGENTS.md 등)일 수 있어 확인 필요.
