## 오늘 끝낸 것 (참고)

- 표정 35장 — 다섯 종목 전부. 편차 0px, 흰 잔재 0.05% 이하
- 접지 그림자 — `Sprite-Lit-Default`는 2D 라이트에 먹혀 안 보인다. **Unlit을 써야 한다**
- 캐릭터 물리를 `Body` 자식에서 루트로 올림 — 이전엔 루트를 옮겨도 안 움직였다
- 전신 캡슐을 발밑 0.55×0.30으로 — 탑다운에서 머리가 벽에 걸리면 안 된다
- 「오늘 장 쉬기」 — 쉬어도 시장은 돈다. 네 장 쉬면 자산 507.9 → 591.4, 주기 1 → 2
- 영지 여섯 곳 — 값이 오를수록 또렷해지는 계단 (0 / 20 / 40 / 80 / 120)

## 되풀이하지 말 것

- **Unity는 PNG를 Multiple로 들여 알파 박스대로 자동 분할한다.** 표정은 반드시 Single로 강제하고
  "서로 다른 칸 1가지"인지 확인한 뒤 쓴다
- **모델 코드를 고칠 때는 플레이를 멈춘다.** 플레이 중 재컴파일하면 돌고 있는 객체는 옛 어셈블리다
- **Codex 요청서는 숫자로 쓴다.** "덜 기울여라"는 또 어긋난다. "원형 상판 세로÷가로 0.45~0.55"라야 맞는다
- **요청서를 고쳐 다시 걸 때마다 Codex 토큰이 든다.** 오늘 세 번 고쳐 건 것이 한도 소진에 보탬이 됐다.
  걸기 전에 요구사항을 다 모아서 한 번에 쓴다

## 10/17 저녁 — 필드 상호작용 (애니메이션을 많이 쓰는 방향)

`CharacterActor`가 몸짓·바라보기·머리 위 표시·말풍선을 맡는다. **새 애니메이션은 Animator에 상태만 추가하면 된다**
(`ActorMotion` 이름과 같은 상태: Cheer · Nod · Shake · Hop). 상태가 없으면 코드로 몸을 조금 움직여 대신한다.

| 언제 | 필드에서 보이는 것 |
|---|---|
| 문 앞에서 E | 주인공이 문 쪽을 돌아본 뒤 선택지 |
| 사람에게 E | 서로 돌아보고, 상대가 「?」 → 말풍선으로 대꾸 + 몸짓(주민 끄덕, 노점상 깡충, 모험단 고개 젓기). 대화창을 열지 않는다 |
| 주인공 근처 | 서 있는 사람이 돌아보고 처음엔 「!」(노점상은 「＄」). 노점상은 이따금 손님을 부른다 |
| 모험단 도착 | 45% 확률로 한 사람이 환호·깡충 + 한마디 |
| 일을 마침 | 주인공 환호(Cheer) + 「＄」 → 선택지로 |
| 나만 아는 소식 | 주인공 깡충 + 「!」 |
| 지하거래소 발견 | 주인공 놀람(Shake) + 「!」 |
| 용사에게 따뜻한 대답 | 주인공 깡충 + 「♥」 |

**만들면 바로 쓰이는 애니메이션 후보**: Nod(끄덕), Shake(고개 젓기·놀람), Hop(반가움), 그 밖에 Bow(인사), Wave(손 흔들기), Think(턱 괴기), Sigh(한숨)
- **용사단 종목(지수형) 상장 (10/17).** 「용사단 (지수)」 100에서 시작, 변동성 0.15, 장마다 내재가치 +0.5%(한 주기 약 +2%). 후원 기한을 넘겨 시나리오가 깨지면 가치 12%로 무너지고 상장 폐지, 보유분은 그 값에 청산. 용병단 종목에 빌려 쓰던 용사 얼굴은 이미 떼었다
- **시나리오 붕괴 → 처음으로 (10/17).** 기한을 넘긴 밤 잠자리에 들면 결산 뒤 붕괴 장면 세 줄("…다시, 처음부터.")이 나오고 인트로로 돌아간다. 저장이 없어 새 판이다
- **상장 흐름 1단계 (10/17).** 용병단은 상장 한 주기 전에 영지에 도착해 무리 지어 다닌다. 상장되면 계속 보이고, 전멸·은퇴하면 사라진다. 영지 모험단 = 거래소 종목(블랙무어 단 / 회색 파수대 / 등불 기사단). 다가가면 "갓 도착 · 다음 주기 상장 예정" 또는 "보유 N주"가 뜬다. 도착할 때 거래소에 "영지에 도착했다 · 예상 공모가" 쪽지
  - 남은 것: 상장 경로(실적·보증·심사), 상장 전 조사로 얻는 정보, 주기마다 새 단이 끝없이 들어오는 생성기, 셀라·브란(개인)을 단으로 정리
- **튜토리얼 뼈대 (10/17).** 지하거래소에 처음 들어가면 8단계로 한 곳씩 비추며 설명한다(종목·가격·호가·주문·자산·정보 기록·시간). 그동안 시간이 멈춘다. 건너뛰기 가능, 새 게임에서 다시 나온다. 단계 목록은 `MarketScreenController.StartTutorialOnce`, 문구는 `Constants.Tutorial.cs`. `UI_Tutorial`은 다른 화면(영지, 첫 익명 의뢰)에도 그대로 쓸 수 있다
