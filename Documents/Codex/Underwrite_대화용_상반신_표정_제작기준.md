# Underwrite 대화용 상반신 표정 제작 기준

작성: 2026-10-16 / 관리: Codex

## 범위와 상태

PortraitFaces_v1 셀라·브란과 v2 scholar·elf·fairy의 제작 기준이다. 사용자는 2026-10-17 요청에서 v1 두 인물이 Unity에서 표정 교체·정렬 상태로 실제 동작함을 확인했다. v2는 PNG 제작·검증을 마쳤으며 사용자 시각 승인 전 시안이다. 상위 아트 규칙은 유지한다. 이번은 PNG까지, Assets 및 Unity 연결 제외다.

## 출력과 고정 원화

- 820×1080, 8bit RGBA. 이름은 face_{인물}_{표정}.png.
- 표정 순서: neutral, happy, anxious, angry, shocked, sad, relieved.
- 전신 크롭 없이 상반신을 새로 그린다. 머리 위·사방에 투명 여백, 가슴 윗부분에서 끝나는 구도. 손·무기·식기 제외, 약한 오른쪽 3/4 각도로 고정.
- 인물별 평상 원화를 먼저 정한다. 새 표정은 이미지 생성 도구로 그린다. 생성된 표정을 정렬한 뒤 얼굴 영역만 합성하여 머리·몸·의상·조명·전체 알파를 고정한다. 코드로 눈·입을 새로 그리거나 변형하여 표정을 대신하지 않는다.
- PNG 단계의 Unity 피봇·PPU는 미설정이다. 후속 임포트는 같은 820×1080 캔버스와 같은 UI 기준점을 사용하고 개별 자동 크롭을 하지 않는다.

## v1 좌표 기준

원점은 왼쪽 위, bbox 끝 좌표는 포함이다. 다른 인물을 아래 좌표에 무조건 확대하지 않는다. 인물별 첫 평상 원화에서 기준을 정한 뒤 해당 인물의 표정에 고정한다.

| 인물 | 알파 bbox (x0,y0,x1,y1) | 머리 꼭대기 y | 평상 눈선 근/원 y | 평균 y |
|---|---|---:|---|---:|
| 셀라 | (44,75,755,838) | 75 | 326.5 / 366.5 | 346.5 |
| 브란 | (46,97,774,823) | 97 | 241.5 / 267 | 254.25 |

기본 상반신 생성 원본 1221×1288을 전체 760×802로 환산하여 캔버스 (30,60)에 배치했다. 전신 크롭이 아니다. 표정 편집 원본 1093×1439는 공통 캔버스로 환산했다. 생성 중 커진 셀라 놀람·브란 분노는 평상 원화의 움직이지 않는 부위를 기준으로 배율·위치를 보정했다. 실제 수치·합성 마스크는 Outputs/PortraitFaces_v1에 보관한다.

셀라의 은색 체인 드롭 귀걸이는 전신 비교에서 누락을 발견하여 이미지 생성 도구로 보완했고 7표정에 동일하게 반영했다. 비대칭 장식은 좌우 반전으로 옮기지 않는다.

## 정렬 검수

- 7장을 동일 좌표에 1/7씩 평균 합성한 겹침 PNG를 남긴다. 표정 영역 밖 RGBA와 전체 알파를 평상 원화에 대해 전수 비교한다. v1은 모두 변경 0픽셀.
- 알파 bbox·머리 꼭대기 y·눈선 y 표를 남긴다. 인물별 최대-최소 편차 10px 이하.
- 눈선 수치는 고정 검출창 안에서 R<150, G<110, B<110인 어두운 눈선·홍채 픽셀 bbox 중앙 y다. 감은 눈은 눈꺼풀 선을 포함한다. 해부학적 눈 중심이나 머리 이동만을 측정하는 값은 아니므로 표식 PNG 및 실제 눈·코·턱 정렬을 함께 확인한다.
- 검출창(x0,y0,x1,y1, 끝 제외): 셀라 (480,315,525,346), (577,352,610,381); 브란 (450,231,488,258), (535,253,562,282). 검출창·방법을 바꾼 수치를 이전과 같은 측정으로 비교하지 않는다.
- v1 측정: 머리 꼭대기 편차 두 인물 0px. 셀라 근/원 눈선 5.5/7.5px, 평균 눈선 6px. 브란 4/1px, 평균 눈선 2px.

## 알파·외형 검수

알파 32 미만 제거, 분리 잡픽셀 제거, 투명 픽셀 RGB 0. 넓은 내부는 불투명, 가는 가장자리·머리카락 틈의 안티앨리어싱은 보존한다. 바깥과 갇힌 흰 배경을 함께 확인하되 흰 의상·갑옷 반사를 밝다는 이유로 지우지 않는다.

흰색 후보 = 알파≥200, RGB 모두≥244, max(R,G,B)-min(R,G,B)≤10. 분모 = 알파≥200 픽셀 수. 1% 미만이어야 하며 수치만으로 배경 제거 완료를 판단하지 않는다.

#141014·흰색·Outputs/GatherPlaces_v1/place_tavern.png 위 합성을 확인한다. HeroCutout_v2의 두 원본 전신과 나란히 비교한다. 셀라는 가는 어깨·검은 포니테일·붉은 리본·남색 코트·은색 귀걸이, 브란은 회색 섞인 머리·수염·은색 판금·분홍 스카프를 유지한다. 동일인물로 읽히는지와 표정 강도는 사용자 시각 승인이 남아 있다.

## 기록과 전달

Outputs/PortraitFaces_v1/에 README, 전체 프롬프트, 생성 원본·시간·해시, 정렬본·보정값·합성 마스크, 좌표표, 검증 JSON, 겹침·배경 합성·전신 비교 PNG를 둔다. 2명×7개의 정지 표정 대체 이미지이며 8방향 애니메이션이 아니다. 검수 HTML의 700ms 교체(한 바퀴 4.9초)는 검수용 값이고 게임용 재생 시간이나 전환 조건을 정하지 않는다.


## v2 최종 PNG 검증 — 2026-10-17

- 사용자 요청으로 scholar·elf·fairy 3명×7표정을 Outputs/PortraitFaces_v2에 추가했다. PNG까지, Assets·Unity 제외. 제작·검증 완료이며 사용자 시각 승인 전 시안이다.
- 820×1080 RGBA 고정. bbox(끝 포함)는 scholar (36,101,783,950), elf (33,66,789,855), fairy (38,108,781,964). 인물별 7장 머리 꼭대기·왼쪽 x 편차 0px, 전체 알파 및 얼굴 합성 마스크 밖 RGBA 변경 0픽셀.
- 21장 흰색 후보 0.004516~0.053841%, 각각 연결 성분1·숨은RGB0·캔버스접촉0. 모든 좌표·개별 수치는 Outputs/PortraitFaces_v2/alignment_table.csv와 verification.json에 보관한다.
- 새 인물의 눈 검출창은 검증 JSON에 따로 기록한다. 눈선 bbox 중심은 안경·속눈썹·닫힌 눈꺼풀의 영향을 받는다. 이번 요청의 10px 판정은 명시한 알파 bbox의 머리 꼭대기 y와 왼쪽 x에 적용하며, 눈선 변화와 실제 머리 이동은 구분한다. v1 검출창의 측정값과 직접 비교하지 않는다.
- 비동기 생성의 참조는 현재 납품 PNG처럼 다른 작업이 갱신할 수 있는 경로를 공유하지 않는다. 인물별 기준 원화를 별도 고정 경로에 저장하고 원본 해시와 참조 경로를 기록한 뒤 표정을 요청한다. 생성 중 구도가 달라졌으면 육안으로 이중 눈·입·안경을 검사하고 재생성한다. 최종 합성·검증은 독립 폴더에서 수행하고 배치 후 해시를 비교한다.
- 최종 PNG와 같은 face_ 파일명을 백업 하위 폴더에 반복하지 않는다. 파일명으로 재귀 검색하는 임포터의 중복 인식을 피하도록 백업·검증본에는 별도 접두사를 붙인다.
