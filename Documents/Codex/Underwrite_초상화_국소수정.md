# Underwrite 초상화 국소 수정

2026-10-17. 적용 사례: Outputs/PortraitFix_v2.

- 코 등 국소 수정은 이미지 생성 도구로 원화를 만든 후 수정 마스크 안에만 합성한다. 코 밖 RGBA·전체 알파·보호 눈 영역·안경테 보존과 표정 사이 코 패치 동일성을 별도로 전수 검사한다.
- 갈색 코 윤곽도 금색 안경과 유사한 RGB 비율을 보일 수 있다. 색 조건만으로 안경 보호 마스크를 만들면 지우려던 코 선까지 보존되어 이중 코가 생긴다. 실제 안경 위치로 범위를 제한하고 확대 검수한다.
- 코 마스크와 눈 검사 사각형이 미세하게 겹칠 수 있다. 두 눈 사각형 전체를 명시적으로 제외하면 기존 눈선과 주변 픽셀 보존을 검증하기 쉽다.
- TextureImporter spriteMode1은 Single이며 유효 Sprite Rect는 전체 텍스처다. spriteSheet 아래 과거 슬라이스 rect를 활성 Rect로 오인하지 않는다. alignment0 피봇은 중앙이며 저장된 잔여 pivot 숫자만으로 판단하지 않는다.
- 이번 코 합성 매개변수·보호 영역·원본은 Outputs/PortraitFix_v2/patch_masks.json 및 before/에 기록되어 있다. 향후 다른 얼굴에 좌표를 그대로 적용하지 않는다.
