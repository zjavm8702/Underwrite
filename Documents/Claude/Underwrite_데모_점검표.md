# 데모 점검표 (2026-10-18, 과장)

사장님이 데모(첫 두 계절, 약 1~2시간)를 직접 돌려 보실 때 보면 좋은 것. 과장이 혼자 정한 것 가운데 **느낌으로만 판단할 수 있는 것**을 위에 모았다.

## 시작

- `Intro` 장면에서 Play → 움직이는 웹툰(클릭·스페이스로 한 칸씩) → 건너뛰기 가능
- 저장이 있으면 왼쪽 위 「이어하기」. 새로 하려면 웹툰을 끝까지 보거나 건너뛰기
- 주의: 과장의 Play 시험 때문에 지금 저장 파일은 시험 상태다. 새로 시작하시는 것을 권한다

## 사장님 눈으로 봐 주셨으면 하는 것 (과장이 정했지만 느낌의 문제)

| 무엇 | 과장이 정한 것 | 확인할 점 | 되돌리기 |
|---|---|---|---|
| 장 속도 | 1배속 틱 15초 → **7.5초**(장 9분) | 가격을 눈으로 따라갈 수 있는가 | `MarketTuningData`의 `MinutesPerRealSecond` 0.3333 |
| 고드릭의 죽음 | 둘째 계절 방패 사정을 놓치면 **고드릭 사망** | 데모에서 너무 세지 않은가 | `PatronageLedger`의 `IsFatal` |
| 장부 맞추기 | 길드 기록실, 더해서 어긋난 단 찾기 → 뜻 고르기 | 재미있는가, 너무 쉬운가 | `Constants.LEDGER_*` |
| 엿듣기 | 여관 홀, 테이블 넷 · 기회 4번 · 경계심 | 「고르는」 맛이 있는가 | `Constants.EAVES_*` |
| 주문서 읽기 | 대장간 꽂이, 여관 소문 하나를 이번 계절·취소 안 된 주문서로 가림 → 맞는 말/헛말 | 미끼(지난 계절·취소)를 가려내는 맛이 있는가, 너무 쉬운가 | `Constants.SMITH_ORDER_*` |
| 주문 나르기 | 주문표 7초 외우고 쟁반 채우기 | 매번 하기 귀찮지 않은가(「대충 끝낸다」 있음) | `Constants.WORK_*` |
| 계절 계획 | 출발 밤 세 달 고르기 + 몽타주 + 편지 | 흐름이 끊기지 않는가 | `SeasonPlan` |
| 거래 화면 | Codex 키트 적용(부분 통과) | 아직 대시보드 같은가 | 커밋 `8f4c6eb` 되돌리기 |
| 대사 전부 | 과장 초안 | 말투·설정이 맞는가 | `Constants.*.cs`의 `TEXT_*` |

## 데모의 흐름 (이렇게 흘러가면 정상)

1. 1년 봄 1일째 오후 — 여관 주인의 부탁 → 여관 주방 일 → 창고에서 지하거래소 발견(웹툰 5~6화)
2. 18시 첫 장(재개장 자리) → 지하 방 → Tab 거래판
3. 2·3·4일째 — 장 두 번씩(3일째는 용사단과 쉬는 날. 영주 시찰은 10/19 삭제)
4. 치유사 사정(1일째부터) — 첫 후원은 강제 안내(용사단 테이블 → 여관 일에서 사정 듣기 → 길드 서기 설명 → 의뢰). 놓치면 피오가 다쳐 돌아온다
5. 4일째 자정 — 출발 장면 → 계절 계획 → 편지(친하면) → 1년 여름 1일째 아침
6. 여름 1일째 — 아침에 여관으로 데려가 귀환 장면(10/19부터 놓칠 수 없음), 18시 재개장(값이 뛴 채 열림, 정보 타임 1·2차에 결과)
7. 여름 2일째 — 방패 사정이 드러난다(편지로 미리 막았으면 이미 해결)
8. 여름 4일째 자정 출발 → 가을 1일째 귀환(고드릭의 생사) → **데모 마무리**
