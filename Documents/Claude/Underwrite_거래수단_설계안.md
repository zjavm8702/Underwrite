# 해가 지나며 열리는 거래 수단 — 설계안 (2026-10-18, 과장)

작업목록 11번 「신용·공매도·원정 결과 내기 (설계만 먼저)」. 기획서 v0.7 §7의 「수단이 열린다」, 10년 골격(3~4년 신용, 5~6년 공매도·원정 내기)을 숫자로 옮긴다.
시장 규모 곡선은 `Underwrite_거품시장_설계안.md`. **아직 코드 없음** — 데모(1년째) 범위 밖이다.

## 0. 원칙

- 수단은 **정보상이 권한다**(이야기 안에서 열린다). 메뉴가 갑자기 생기지 않는다 — 「손님, 이제 빌려서도 사 보시겠습니까」
- 셋 다 **원정 휴장 갭과 맞물린다.** 출발 밤에 무엇을 들고 가느냐가 판단의 중심이라, 빌린 돈·빌린 주식은 휴장 동안 피할 수 없는 위험이 된다
- 파산 규칙(한 번 재기, 두 번째 게임오버)은 그대로 — 수단이 파산으로 가는 길을 빠르게 만들 뿐이다
- 셋 다 쓰면 쓸수록 **거품을 키운다**(쏠림 지표 — 이야기의 결말 조건 후보). 「투자 선택이 이야기의 선택」

## 1. 신용 — 지하 대부 (4년째 봄)

| 항목 | 값 | 이유 |
|---|---|---|
| 빌릴 수 있는 돈 | 순자산의 1배까지 | 2배면 갭 한 번에 끝난다. 1배면 「위험하지만 버틸 수 있다」 |
| 이자 | 계절마다 빚의 6% (재개장에 자동 차감) | 시장 유입(4년째 +14%)보다 낮아 쓰고 싶게, 정보 없이 쓰면 손해 |
| 담보 부족 | 재개장 직후 (총자산 − 빚) / 총자산 < 30%면 정보상이 그 장 안에 **강제 청산**(값이 큰 종목부터 시장가) | 장중이 아니라 재개장 직후만 — 갭의 무게가 그대로 실린다 |
| 갚기 | 아무 때나 현금으로 | |

- 화면: 장부 줄에 「빚」 칸 하나, 주문 칸에 「빌려서 산다」 체크. 강제 청산은 팝업으로 확인을 받는다(청산 알림과 같은 방식)

## 2. 공매도 — 빌려 판다 (5년째 봄)

| 항목 | 값 | 이유 |
|---|---|---|
| 빌릴 수 있는 수량 | 순자산의 0.5배어치까지 | 손실에 끝이 없으니 신용보다 작게 |
| 빌림 값 | 계절마다 빌린 가치의 4% | |
| 강제 상환 | 재개장 직후 손실이 순자산의 50%를 넘으면 시장가로 되사서 갚게 함 | |
| **용사단 종목** | 공매도할 수 없다 — 정보상: 「그분들에게 반대로 거는 건 받지 않습니다」 | 주인공이 응원하는 단에 반대로 거는 길을 막는다(원작 설정 보호). 대신 다른 단의 몰락에 거는 냉정함은 열어 둔다 |

- 고위험 단이 무너지는 데 걸면 돈은 되지만, 그 단이 무너지는 것이 국경을 약하게 한다 — 이야기 쪽 대가(5~6년째 국경 사건과 이어서 설계)

## 3. 원정 결과 내기 — 증서 (5년째 가을)

- 재개장 때 드러날 **한 단의 원정 결과**(도감의 대장간 사정·여관 소문)에 거는 증서. 「오른다 증서」·「내린다 증서」
- 값: 장 사람들이 보는 확률(소문을 들은 정도 = `CODEX_TAVERN_CROWD_SHARE`)로 정해진다. 0~1 사이, 맞으면 1, 틀리면 0
- **정보 모으기의 값이 그대로 돈이 되는 수단**이다 — 주문서 읽기로 소문을 확인했으면, 장 사람들이 반쯤 믿는 소문의 증서를 싸게 살 수 있다
- 한 계절 한 단에 순자산의 10%까지(정보 독점으로 돈을 찍어 내지 않게)

## 4. 시장 규모와의 관계

| 해 | 열리는 것 | 「잘함」 목표 자산(거품 설계안 표) |
|---|---|---|
| 1~3 | 현금 거래만 | 500 → 5,200 |
| 4 | 신용 | 15,000 — 신용으로 「보통」도 이 근처에 닿는다 |
| 5 | 공매도 · 원정 내기 | 48,000 |
| 7~8 | (큰손) 주문이 호가를 쓸어 간다 | 45만 ~ 116만 |
| 9 | 붕괴 — 신용·공매도가 양날 | 빠져나왔는가 |

## 5. 구현 메모 (그때 할 일)

- `Wallet`에 빚·빌린 주식 줄, 저장(`WalletState`)에 함께
- 재개장 처리 순서: 유입 → 도감 결과 → 이자·빌림 값 → 담보 검사(강제 청산) → 갭
- 시험: 갭으로 담보가 깨지는 경우, 용사단 공매도 거절, 증서 정산
