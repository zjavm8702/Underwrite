# 화면별 틀과 단추 v1 — 거래소 그림을 돌려 쓰지 않게

## 왜 필요한가

지금 **모든 화면이 거래소 그림을 돌려 쓴다.** 사장님 판정: "너무 팝업, 버튼, 탭을 돌려쓰고 있는 느낌이다."

| 지금 쓰는 그림 | 쓰이는 곳 |
|---|---|
| `market_panel.png` | 거래소 패널 · **대화상자 · 팝업 · 정보 타임 장면 상자** |
| `ui_button_normal/pressed/disabled.png` | 거래소 단추 · **대화 「다음」 · 대화 선택지 · 팝업 단추 · 영지 하단 단추** |

**거래소는 지금 그림(`market_panel`, `ui_button_*`, `ui_tab_*`, `ui_field`) 그대로 간다.**
나머지 화면에 쓸 그림을 새로 만든다. 화면마다 손에 쥐는 물건이 다르게 보여야 한다.

## 색과 세계

거래소 납품분(`Outputs/MarketUI_Parchment_v1`, `Outputs/MarketUI_Controls_v1`)과 **같은 세계, 다른 물건**이다.

- 종이 `#F2E7D2`, 잉크 `#2A2118`, 흐린 글자 `#5B4D3E`
- 대화·팝업·영지는 따뜻하게, 정보 타임 상자만 어둡게
- 빛은 왼쪽 위에서. 그림자는 테두리 안쪽에만. **바깥 그림자·후광을 넣지 않는다** (코드가 붙인다)

## 크기와 늘려 쓰기

9-slice로 늘려 쓴다. 테두리 장식은 **Border 안에서 끝나야** 한다. 가운데는 늘어나므로 결이 늘어져 보이지 않게 **가운데는 거의 평평하게** 둔다.

| 쓰이는 곳 | 화면 크기 (px) |
|---|---|
| 대화 상자 | 폭 1100~1300 × 높이 420~700 |
| 선택지 | 폭 1000~1200 × 높이 64~84 |
| 팝업 | 폭 560 × 높이 260~420 |
| 영지 하단 단추 | 폭 180 × 높이 48 |
| 영지 안내판 | 폭 400 × 높이 120 |

## 눌림 연출

눌림은 코드가 붙인다(크기 0.96배로 줄었다가 돌아오기 + 눌린 그림으로 바꾸기). 그래서 **normal과 pressed는 크기·테두리 위치가 같아야 한다.** 글자 자리가 어긋나면 눌릴 때 글자가 튄다.

## 검수

1. 각 PNG의 9-slice Border 안에 장식이 끝나는지 — Border 선을 그은 `borders_overlay.png`
2. 실제 화면 크기로 늘린 미리보기 `stretched_preview.png` (위 표의 크기로)
3. normal / pressed 쌍의 테두리 위치 차이 px — 0이어야 한다
4. 알파 잔점, 숨은 RGB, 캔버스 가장자리 접촉

## 범위

**PNG까지.** 최종 PNG는 `Assets/UI/Images/`에 위 파일 이름으로 둔다(새 파일, 기존 파일을 덮어쓰지 않는다).
기록은 `Outputs/UIFrames_v1/`. Unity 연결(USS 적용, 9-slice 설정, 눌림 연출)은 Claude Code가 한다.
