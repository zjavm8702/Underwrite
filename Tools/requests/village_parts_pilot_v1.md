# 영지 파츠 시범 v1 — 여관 한 블록을 사람 크기에 맞춰 나눠 그린다

영지 전체를 다시 그리기 전에 **여관 한 블록만** 새 방식으로 만든다.
이 결과를 보고 영지 전체(v3)를 같은 규격으로 건다.

## 왜 바꾸나 — v2의 문제 세 가지

v2를 실제 게임 화면(캐릭터 키 128~136px)에서 재어 보니 이렇다.

| 대상 | v2 | 캐릭터 키 대비 | 맞는 값 |
|---|---|---|---|
| 여관 문 높이 | 약 90px | **0.7배** — 사람이 문보다 크다 | 1.2~1.3배 |
| 여관 건물 전체(2층+지붕) | 약 290px | **2.3배** — 미니어처 | 3.5~4.5배 |
| 바닥 돌 한 장 | 약 50px | **0.4배** — 판석이 너무 크다 | 1/6~1/8 |

1. **크기가 사람과 안 맞는다.** 위 표다. 건물은 작고 바닥 돌은 크다.
2. **통짜 그림이라 캐릭터가 무엇의 뒤로도 못 간다.** 가로등·나무·처마 뒤를 지나도 캐릭터가 위에 그려진다.
   그래서 바닥에 선 사람이 아니라 그림 위에 붙인 스티커로 보인다.
3. **흐리다.** v2는 1672×941로 생성해 2.3배 키웠다. 캐릭터는 선명한데 배경은 뭉개져 있다.

그래서 이번에는 **바닥판 한 장 + 세워진 사물을 하나씩 뗀 PNG**로 만든다.
게임에서 사물마다 발밑 높이로 앞뒤를 정렬하고, 불빛·연기·나무 흔들림은 코드가 붙인다.

## 축척 — 이번 작업의 핵심. 숫자로 맞춘다

기준은 **사람 키 135px**이다. 화면 1920×1080에서 1/8이고, 이 크기가 게임과 1:1이다.
실제 주인공 그림으로 재라: `Assets/Images/Characters/Protagonist/Idle/S/idle_S_00.png`의
알파 32 이상 실루엣을 키 135px가 되도록 줄인 것이 기준 사람이다.

| 대상 | 캐릭터 키 대비 | 픽셀 (사람 135px 기준) |
|---|---|---|
| **사람 문** 높이 (문턱~문틀 위) | **1.2~1.3배** | 162~176px |
| **2층 건물** 접지~용마루 | **3.5~4.5배** | 473~608px |
| 1층 창문 아래턱 높이 | 0.5~0.6배 | 68~81px |
| **바닥 돌 한 장** 긴 변 | **1/6~1/8** | 17~23px |
| 술통 높이 | 0.5~0.6배 | 68~81px |
| 둥근 탁자 상판 높이 | 0.4~0.45배 | 54~61px |
| 가로등 | 1.6~2배 | 216~270px |
| 나무 | 3~5배 | 405~675px |
| 화분 | 0.25~0.35배 | 34~47px |

**문과 사람을 나란히 세운 합성에서 "문이 사람보다 크다"가 한눈에 보여야 한다.** 숫자가 맞아도 그림이 그렇게 안 보이면 다시 한다.

## 시점·빛·화풍 — v2에서 통과한 것은 유지

- 시점: **원형 상판 세로÷가로 0.45~0.55.** 우물·탁자·통 뚜껑 중 둘 이상을 재서 적는다
- 빛: **왼쪽 위**에서 온다. 그림자는 오른쪽 아래로
- **한낮의 중성광**으로 그린다. v2처럼 노을빛 금색으로 물들이지 않는다. 캐릭터가 중성광이라 배경만 금색이면 따로 논다
- **불빛 후광·번짐(블룸)을 그리지 않는다.** 등불 유리와 창문은 밝은 색으로 칠하되 둘레로 번지는 빛은 넣지 않는다. 빛은 코드가 2D 라이트로 붙인다
- 비도트, 셀 채색 계열. 캐릭터와 같이 **외곽선이 있는 깔끔한 채색**에 가깝게. v2보다 덜 뭉개지게
- 글자·숫자·간판 문구·사람을 그리지 않는다

## 해상도 — 키워서 쓰지 않는다

- 사물 PNG는 **생성 해상도보다 크게 확대하지 않는다**(배율 1.0 이하). 크게 생성해서 줄인다
- 바닥판은 확대 배율 **1.3 이하**
- 각 파일의 생성 해상도와 최종 해상도, 배율을 기록한다

## 무엇을 납품하나

블록 크기는 **1920×1080 한 화면**이다. 여관이 위쪽 가운데에 있고, 앞에 바깥 자리가 있다.

### 1. 바닥판 `ground.png` — 1920×1080, 불투명

- **높이가 없는 것만** 그린다: 돌길, 흙, 풀밭, 낮은 연석(사람 발목 아래)
- 세워진 사물이 설 자리 밑도 **바닥으로 채운다.** 사물을 떼어 냈을 때 구멍이나 흔적이 없어야 한다
- 사물들의 **그림자는 바닥판에 그린다.** 배치가 고정이니 그림자 위치도 고정이다. 오른쪽 아래로, 사물 발밑에서 시작
- 바닥 돌은 위 축척표대로 작게. 무늬는 얌전하게

### 2. 세워진 사물 — 하나에 PNG 하나, RGBA

최소 이만큼:

| 파일 | 수 |
|---|---|
| `inn.png` 여관 건물 (2층, 문 하나, 문 앞 계단 포함) | 1 |
| `tree_a.png`, `tree_b.png` | 2 |
| `lamp_a.png`, `lamp_b.png` 가로등 | 2 |
| `table_a.png`, `table_b.png` 둥근 탁자 + 의자 | 2 |
| `barrel_*.png` 술통 | 2~3 |
| `pot_*.png` 화분 | 3~4 |

- 실루엣 바깥 **알파 0**, 가장자리만 좁은 안티앨리어싱. 알파 32 미만 제거 후 잘림 재검사
- **그림자를 사물 PNG에 넣지 않는다**(바닥판에 있다). 후광도 넣지 않는다
- 사물끼리 겹친 채로 그리지 않는다. 나무가 지붕을 가리는 식의 겹침은 **배치로** 만든다

### 3. 배치표 `layout.json`

사물마다 아래를 적는다. 좌표는 **바닥판 기준 왼쪽 위 원점 px**.

```json
{
  "person_height_px": 135,
  "parts": [
    {
      "file": "lamp_a.png",
      "size": [w, h],
      "foot": [x, y],
      "pivot_in_png": [px, py],
      "footprint": [[x, y], [x, y], [x, y], [x, y]],
      "anchors": { "light": [[x, y]] }
    }
  ]
}
```

- `foot`: 그 사물이 **바닥에 닿는 앞쪽 가장자리의 가운데**를 바닥판 좌표로. 게임은 이 Y로 앞뒤를 정렬한다.
  캐릭터 발이 이 선보다 위(화면 위쪽)에 있으면 사물 뒤에, 아래면 앞에 그려진다
- `pivot_in_png`: 같은 점을 **그 PNG 안의 좌표**로 (왼쪽 위 원점)
- `footprint`: 바닥에 닿는 면을 바닥판 좌표 다각형으로. **사람이 못 들어가는 자리**다. 건물은 벽 밑동, 가로등은 기둥 밑만
- `anchors`: 코드가 효과를 붙일 자리. 바닥판 좌표로
  - `light` — 등불 유리, 불 켜진 창문 가운데
  - `smoke` — 굴뚝 꼭대기
  - `door` — 여관 문 앞, 캐릭터가 서서 말을 거는 자리
  - `sway` — 나무 줄기 꼭대기(그 위만 흔든다)

### 4. 걸을 수 있는 마스크 `walkable.png` — 1920×1080

v2와 같다. 흰 255 통행 / 검정 0 막힘, 중간값 없음. **`footprint`만 막는다.**
지붕·나무 잎처럼 발이 닿지 않는 곳은 막지 않는다 — 그 밑은 캐릭터가 걸어 들어가 가려져야 한다.

## 검수 — 숫자로 적는다

1. **축척표 전 항목 실측값**과 캐릭터 키 대비 배율. 범위 밖이면 실패로 적는다
2. **원형 상판 세로÷가로** 둘 이상
3. **재조립 일치**: 바닥판 위에 `layout.json`대로 사물을 올린 결과를 `assembled.png`로 낸다.
   사물 경계에 바닥판의 구멍·흔적이 보이는지 확대해 확인하고 적는다
4. **앞뒤 가림 합성** `depth_test.png`: 기준 사람을 다섯 자리에 세운다 —
   여관 문 앞, 가로등 바로 뒤, 가로등 바로 앞, 나무 줄기 뒤, 탁자 옆.
   `foot` Y로 정렬해 그린다. 뒤에 선 사람이 실제로 가려지는지 본다
5. 각 PNG의 알파 분리 성분, 숨은 RGB, 캔버스 가장자리 접촉
6. 생성 해상도 → 최종 해상도 배율 표
7. v2 여관 자리(`Outputs/VillageGround_v2_accepted/village_ground.png`의 여관 주변)와 나란히 둔 비교 `v2_compare.png`

## 범위

**PNG까지.** `Outputs/VillagePartsPilot_v1/`에 납품한다. `Assets/`에는 쓰지 않는다.
Unity 연결(정렬, 충돌, 라이트, 연기, 흔들림)은 Claude Code가 한다.
v2 산출물은 건드리지 않는다.
