## 바닥 기준 (숫자)

좌표·크기는 room_plate 1배(2880×1620) 기준.

1. **위에서 본 불규칙 판석.** 크기가 다른 사각·다각 판석(가로 40~80px, 세로는 가로의 0.5~0.8 — 15도 시점 눌림 포함)을 엇갈려 깐다. **같은 줄눈이 판석 3개 넘게 이어지지 않게.** 뒷벽 돌과 모양·크기를 다르게(벽은 둥근 막돌, 바닥은 평평하게 깎은 판석)
   - 측정: 행 평균 표준편차 / 열 평균 표준편차 ≤ **1.3**
2. **선명하게.** 게임 해상도에서 늘리지 않는다 — 생성·질감 원본은 최종 1:1 이상(확대 배율 ≤ 1.15). 판석 윤곽은 1~2px 짙은 줄눈, 베개처럼 부푼 하이라이트 금지
   - 측정: 바닥 가운데 라플라시안 분산 ≥ **28**(뒷벽 이상)
3. **명도 구조.** 빛 번짐은 그리지 않는다(코드가 촛불 Light2D를 얹는다). 대신 면의 닳음과 그늘:
   - 동선(계단 아래 (320,690) → 테이블 사이 → 칠판 앞 (1000,340)·카운터 앞 (2330,950)) 판석은 매끈하고 **명도 +5~8**, 모서리가 닳아 둥글게
   - 벽에서 150px 안은 점점 어둡게, 벽 밑 24~40px에 **접지 그림자(명도 −20~30%)**. 구석 평균 명도 ≤ **45**
   - 바닥 가운데 평균 명도 ≤ 뒷벽 + 5 (지금 75 → 65~70 정도)
   - 판석끼리의 명도 차(국소 표준편차) 6~12 — 사람(135px)이 바닥에 묻히지 않게
4. **이야기 흔적.** 지하 술집 겸 거래소다. 젖은 자국 셋(짙은 갈색, 명도 −8~−12, 가장자리가 불규칙 — 둥근 얼룩 금지, 붉은 계열 금지), 깨진 판석 둘·셋, 갈아 끼운 색 다른 판석 몇 장, 카운터 앞에 작은 배수 철망 하나 정도. 반복 배치 금지
5. **반복 금지.** 질감을 타일로 깔았으면 같은 무늬가 보이지 않게(회전·여러 장·마스크). 자기상관 확인 그림을 tile_check에 넣는다
6. **색.** 벽과 같은 따뜻한 회갈색 계열, 채도 낮게. 차가운 회색·초록 기 금지
