**`inn.png`, `tree_a/b.png`, `lamp_a/b.png`, `table_a/b.png`, `pot_a/b/c.png`는 다시 그리지 않는다.** v1 파일을 그대로 v2 폴더로 복사해 쓴다.

판정 기준은 **수치가 아니라 실제 게임 화면에서 어색하지 않은가**다. 아래 셋이 화면에서 어색했다.

## 고칠 것 하나 — 바닥이 벽지처럼 보인다 (가장 크다)

v1 기록에 스스로 적었듯이 바닥은 생성 원본의 가운데를 잘라 **24px 이음매로 타일처럼 반복**했다.
화면에서는 똑같은 회색 벽돌이 끝없이 깔린 벽지로 보인다. 그 위에 선 건물과 사람이 다른 그림에서 오려 붙인 것 같다.

- **반복하지 않는다.** 1920×1080 바닥판 전체를 한 번에 그린다. 타일링·복제·거울 반복 금지.
  생성 해상도가 모자라면 2~4조각으로 나눠 생성하고 이어 붙이되, **같은 무늬가 두 번 나오면 안 된다**
- **색을 따뜻하게.** 지금은 차가운 회색(무채색)이다. 건물의 회벽·목재·기와와 같은 빛 아래 있는 돌이어야 한다.
  옅은 황토·베이지가 섞인 돌로. v1 사물들의 평균 색온도와 맞춘다
- **바닥에 사연을 넣는다.** 사람이 많이 다니는 길(문 앞→광장)은 돌이 닳아 매끈하고 밝다.
  가장자리·사물 밑동 주변은 흙이 끼고, 돌 틈에 풀이 조금 난다. 빠진 돌, 금 간 돌, 웅덩이 자국 한두 군데.
  다만 **얌전하게** — 캐릭터가 지나갈 때 어지러우면 안 된다
- **건물 밑동에 경계를 그린다.** 여관 돌 기단이 바닥과 만나는 선을 따라 흙·이끼·짙은 틈.
  지금은 기단이 바닥 위에 얹혀 있는 것처럼 보인다
- 바닥 돌 크기는 **v1 그대로 17~23px.** 이것은 맞았다
- 사물의 그림자는 v1처럼 바닥판에 그린다. 아래 「셋」을 반영한다

## 고칠 것 둘 — 술통이 떠 보인다

- **뚜껑 세로÷가로 0.45~0.55.** v1은 0.42·0.39로 실패했다(직접 기록한 값)
- 높이는 v1 그대로 68~81px
- **자리를 옮긴다.** v1은 가로등 `lamp_a` 바로 뒤에 겹쳐 있어 등에 꽂힌 것처럼 보였다.
  여관 벽 기단에 붙여 문 왼쪽에 둔다. 두 통을 붙여 놓거나 하나를 눕혀도 좋다. 가로등과 화면에서 겹치지 않게
- 바닥에 닿는 밑면이 보이게. 통 밑동이 바닥과 만나는 곳에 짙은 접지 그림자

## 고칠 것 셋 — 작은 사물의 접지가 약하다

화분·탁자 다리·의자 다리·술통 밑이 바닥에 닿은 느낌이 덜하다.

- 바닥판에서 각 사물의 **밑동 바로 아래에 짧고 짙은 접지 그림자**(사물 폭만큼, 두께 3~6px)를 그린다.
  오른쪽 아래로 길게 늘어지는 그림자와 **별개**다. 접지 그림자가 없으면 길게 늘어진 그림자가 있어도 떠 보인다
- 접지 그림자는 사물 PNG가 아니라 **바닥판에** 그린다

## 그대로 지킬 것

- 1920×1080, 사람 135px 기준, 빛은 왼쪽 위, 한낮의 중성광, 번짐 없음, 글자·사람 없음
- `layout.json` 형식은 v1과 같다. 술통 `foot`·`pivot_in_png`·`footprint`만 바뀐다
- `walkable.png`는 footprint만 막는다

## 검수

1. **반복 검사**: 바닥판을 128×128 칸으로 나눠, 칸끼리의 픽셀 차이가 거의 0인(같은 무늬) 쌍이 있는지 센다. **0쌍**이어야 한다
2. **색온도**: 바닥판 평균 색과 사물 PNG 평균 색의 RGB를 적는다. 바닥이 무채색(R≈G≈B)이면 실패
3. 술통 뚜껑 세로÷가로 두 개
4. 바닥 돌 크기 표본 10개 (17~23px)
5. `assembled.png`, `depth_test.png`(v1과 같은 다섯 자리), v1과 나란히 둔 `v1_compare.png`
6. 사물 밑동 다섯 곳(술통, 화분, 탁자 다리, 가로등, 여관 기단 모서리)을 4배로 확대한 `contact_detail.png`
