# 정보 출처 표식 v1

## 왜 필요한가

지하세계로 들어오는 소식에는 **출처가 붙는다**. 같은 내용이라도 여관에서 주워들은 이야기와 길드 기록에 남은 사실은 무게가 다르다. 기획서 §8은 "출처와 함께 제공해 추론 근거로 쓴다"고 적었다.

지금은 출처가 글자로만 적힌다("여관 소문 · 셀라"). 한눈에 구분되는 표식을 붙인다.

## 납품할 PNG 5장

모두 **96×96, RGBA, 단색 실루엣**. 흰색(`#FFFFFF`) 한 가지로 그리고 알파로 형태를 낸다. 색은 코드에서 칠한다.

| 파일 | 출처 | 성격 | 그릴 것의 방향 |
|---|---|---|---|
| `mark_tavern.png` | 여관 소문 | 가장 가볍다. 틀릴 수 있다 | 술잔, 입에서 나온 김 같은 것 |
| `mark_guild.png` | 길드 기록 | 가장 무겁다. 공식 기록이다 | 도장, 봉인, 장부 |
| `mark_letter.png` | 사적 편지 | **나만 아는 정보**가 주로 여기서 온다 | 접힌 편지, 밀랍 |
| `mark_board.png` | 시장 게시판 | 이미 다 아는 이야기다 | 못 박힌 종이, 게시판 |
| `mark_broker.png` | 중개인 유출 | 신뢰도가 낮고 의도가 섞여 있다 | 반쯤 가린 얼굴, 손, 귓속말 |

## 실제 크기

화면에서 **20~28px**로 쓴다. 96×96 원본이 1/4로 줄어든다. 그 크기에서 **다섯 개가 서로 구분되어야 한다** — 이게 이 작업의 유일한 성패 기준이다. 예쁘지만 작아지면 다 비슷해 보이는 것은 실패다.

구분을 위해 **실루엣의 바깥 윤곽을 서로 다르게** 잡는다. 안쪽 세부로 구분하려 하면 작아질 때 사라진다.

## 지켜야 할 것

- **글자를 넣지 않는다.**
- 흰색 단색 + 알파. 회색조 음영 금지
- 96×96 안에서 상하좌우 **6px 이상 여백**
- 다섯 장의 시각적 무게를 맞춘다. 한 표식만 유난히 크거나 빽빽하면 줄에서 튄다
- 앞서 납품한 `MarketUI_Icons_v1`과 같은 손길이어야 한다. 획 굵기와 마감을 맞춘다

## 검수에 넣을 것

- 다섯 장을 20px·24px·28px로 줄여 나란히 놓은 비교 이미지. **그 크기에서 서로 구분되는지**가 핵심이다
- 잉크색(`#2A2118`)과 종이색(`#F2E7D2`) 두 바탕에 각각 올린 미리보기
- 각 표식의 알파 면적 비율
- 기존 `Assets/**/*.meta` 해시 변동 없음 확인

## 범위

**PNG까지.** `Outputs/InfoSourceMarks_v1/`에 납품한다. `Assets/`에는 쓰지 않는다.
