# 지하 방 v1 — 바닥판과 사물 (사람은 v2)

## 왜 필요한가

여관 창고 아래 지하거래소는 이 게임의 두 번째 무대다. 지금 `Underworld` 장면은 **갈색 상자와 초록 사각형**뿐이다
(참고 캡처 `Outputs/UnderworldRoom_v1/reference_current_room.png`). 데모(첫 두 계절)에서 가장 눈에 띄는 빈자리다.

영지와 **같은 파츠 방식**으로 만든다: 바닥판 한 장 + 세워진 사물 PNG + `layout.json`. 사람이 그 사이를 걷는다.
기준은 영지 납품(`Outputs/VillagePartsFull_v1`·`v2`)과 시범 v3(`Outputs/VillagePartsPilot_v3`)이다.

## 분위기

- **술 창고를 개조한 비밀 거래장.** 낮은 아치형 돌 천장, 벽돌·돌 벽, 술통이 아직 한쪽에 쌓여 있다
- 어둡지만 탁하지 않게. 테이블마다 촛불·등잔(불빛 번짐은 그리지 않는다 — 코드가 붙인다)
- 영지(따뜻한 낮)와 대비: **차갑고 낮은 채도, 녹슨 놋쇠·검은 나무.** 지하 정보창(`Assets/UI/Images/scene_box.png`)과 같은 재료
- 금융 거래소가 아니라 **판타지 뒷골목 도박장 + 장부 방**. 현대 물건 없음

## 규격 (영지와 같다)

| 항목 | 값 |
|---|---|
| 시점 | 캐릭터와 같은 **15도** |
| 사람 키 | **135px** (1배 기준) |
| 방 크기 | **2880 × 1620 px** (1배). 화면(1920×1080)보다 조금 크다 — 카메라가 따라간다 |
| 사물 해상도 | **2배로 그린다**(사람 270px 기준). `layout.json` 좌표는 1배, 사물 PNG의 크기·pivot은 2배 PNG 기준 |
| 빛 | 왼쪽 위. 불빛 번짐·후광·접지 그림자 그리지 않음 |

## 배치 (지금 게임의 자리 — ±120px 안에서 맞춘다)

방 왼쪽 위가 (0,0), y는 아래로. 지금 장면 좌표를 1배 px로 옮긴 것이다.

| 무엇 | 자리 (1배 px, 발밑/중심) | 비고 |
|---|---|---|
| 들어오는 계단(창고에서 내려옴) | (250, 1350) 부근, 왼쪽 아래 | 주인공이 여기서 시작한다 |
| 둥근 테이블 다섯 | (576, 486) · (672, 1026) · (1296, 378) · (1248, 810) · (1296, 1296) | 의자 3~4개씩. 투자꾼이 앉는다(v2) |
| 주식판(칠판) | 중심 (2304, 368), 폭 480 × 높이 250 | 벽에 걸린 큰 칠판. 칸만 있고 **글자·숫자 없음**(코드가 쓴다) |
| 카운터 | 중심 (2266, 1098), 세로로 긴 모양(폭 115 × 길이 576) | 오른쪽. 뒤에 정보상이 선다(v2, (2381,1098)) |
| 술통·상자 더미 | 벽을 따라 2~3곳 | 막힌 곳 |
| 기둥·아치 | 2~4개 | 방이 넓은 상자로 보이지 않게 |

## 납품

1. `room_plate.png` — 바닥 + 벽(벽은 위쪽과 좌우 테두리, 사람이 벽 앞에 선다). 2880×1620(1배) 또는 5760×3240(2배) 중 하나, layout.json에 적는다
2. 사물 PNG(2배): `table_round_a.png`, `table_round_b.png`(의자 포함, 모양 다르게 둘), `stock_board.png`, `counter.png`, `barrels_a.png`, `crates_a.png`, `pillar.png`, `stairs_entry.png`, 촛대·등잔 소품 1~2
3. `layout.json` — 영지 `layout.json`과 같은 형식(`person_height_px`, 사물마다 `file`·`size`·`pivot_in_png`·`foot`·`footprint`·`block`). 테이블은 **의자 자리 좌표**(`anchors.seats`)를, 주식판은 **글자 쓸 칸의 사각형**(`anchors.board_text`)을, 카운터는 **정보상 자리**(`anchors.informant`)를 넣는다
4. 검수: 사람(135px)을 테이블 사이·카운터 앞·칠판 앞에 세운 `depth_test.png`, 전체를 한 장으로 합친 `composite_preview.png`

**PNG와 layout.json까지.** `Assets/`에는 쓰지 않는다. 납품 폴더 `Outputs/UnderworldRoom_v1/`.
