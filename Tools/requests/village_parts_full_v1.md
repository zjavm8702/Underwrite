# 영지 전체 지도 v1 — 파츠 방식으로 영지를 완성한다

시범 v3(`Outputs/VillagePartsPilot_v3/`)에서 정한 방식을 영지 전체로 넓힌다.
**바닥판 + 세워진 사물 PNG + `layout.json`.** 사물은 발밑 높이로 앞뒤가 정렬되고, 사람이 그 사이를 걸어 다닌다.

판정은 **실제 게임 화면에서 어색하지 않은가**다. 수치 통과만으로 끝내지 않는다.
지금 영지(`Outputs/VillageGround_v2_accepted/village_ground.png`, 통짜 한 장)는 사람과 따로 논다. 이것을 대체한다.

## 반드시 지킬 기준 (숫자로)

| 항목 | 값 |
|---|---|
| 시점 | 캐릭터와 같은 **약 15도**. 원형 상판(우물·탁자·통)의 세로÷가로 **0.45~0.55** |
| 사람 키 | **135px** (지도 축척, 1배 기준). `Outputs/VillagePartsPilot_v3/person_135.png` |
| 문 높이 | 사람의 1.2~1.3배 (160~175px) |
| 2층 건물 높이 | 사람의 3.5~4.5배 (470~610px) |
| 빛 | 왼쪽 위, 한낮 중성광. 그림자는 오른쪽 아래 |
| 그리지 않는 것 | 불빛 번짐·후광·창 불빛 글로, **사물 원본의 접지 그림자** (코드가 붙인다) |
| 바닥 판석 | 불규칙 다각형, 가로 **35~55px**(평균 45), 세로는 가로의 **0.45~0.55배**, 줄눈 2~3px 옅게 |
| 바닥 어지러움 | 흑백 − 가우시안 반지름 4px 블러 차이의 표준편차 **12~20** (시범 v3 = 17.4) |
| 바닥 색 | 따뜻한 색, 평균 RGB (180, 152, 122) 근처 |
| 화풍 | 시범 v3 사물(`inn.png`, `tree_a.png`, `lamp_a.png` …)과 같은 세계, 비도트 |

**시범 v3의 미달을 고친다:** 판석 10개 중 6개가 너무 납작했다(세로÷가로 0.31~0.44). 이번에는 **표본 10개 중 8개 이상이 0.45~0.55**여야 한다.

## 지도 크기와 해상도

- 지도 전체 **3840 × 2160 px** (1배 기준). 화면(1920×1080)이 지도의 1/4을 보여 준다. 지금 영지와 같은 크기다
- **카메라가 최대 1.7배까지 확대한다.** 그래서:
  - **세워진 사물은 2배 해상도로 그린다** — 사람 270px 기준으로 그린 PNG를 납품한다. `layout.json`의 좌표는 모두 **1배 지도 기준**으로 적고, 사물 PNG의 크기와 pivot만 2배 PNG 기준으로 적는다(아래 형식)
  - **바닥판은 1배(3840×2160)로 둔다.** 다만 한 번 생성한 작은 그림을 크게 늘리지 않는다. **어느 부분도 원본보다 1.15배 넘게 늘어나지 않게**, 여러 조각을 각각 그려 이어 붙인다. 이음매는 보이지 않아야 하고, 같은 조각을 반복하지 않는다(128×128 칸 반복 검사 0쌍)

## 장소 — 여섯 곳과 문 위치

문 위치는 지금 게임의 장소 좌표다. **±150px 안에서** 맞춘다(넘으면 이유를 적는다). 좌표는 지도 왼쪽 위 기준 px, 문 앞 사람이 서는 자리.

| 장소 | `place` 값 | 문 앞 (x, y) | 그림 |
|---|---|---|---|
| 여관 (지하거래소 입구 = 여관 창고) | `inn` | (775, 704) | 2층 목골조. 영지에서 가장 큰 건물. 옆이나 뒤에 **창고 문**(지하로 내려가는 입구 — 지금은 그냥 창고 문처럼 보이면 된다). 간판 |
| 영주관 | `manor` | (1949, 637) | 지도 위쪽 가운데. 돌로 지은 단정한 2~3층, 깃발 하나. 영지에서 가장 격식 있는 건물 |
| 길드 기록실 | `guild` | (3149, 823) | 2층. 서류·문서 느낌(창가 서류 더미, 게시된 공고). 간판 |
| 대장간 | `smith` | (583, 1548) | 1층 반. 돌 굴뚝, 앞마당에 모루·숫돌·쌓인 장작. 열린 작업장 |
| 시장 게시판 + 노점 셋 | `board` | (3013, 1532) | 게시판 하나와 **노점 셋**(천막 지붕 — 과일·천·잡화). 노점 앞에 사람이 설 빈자리 |
| 우물 광장 | `well` | (1920, 1224) 근처가 광장 가운데 | 우물(시범 v3처럼 원형), 가로등 둘 이상, 벤치나 화분. **지도 한가운데의 넓은 빈 광장** — 주인공이 처음 서는 곳 |

**길:** 여섯 곳이 광장을 중심으로 이어진다. 문 앞에서 광장으로 닳아서 밝은 길(시범 v3처럼).

## 종족 건축 — 영지는 여러 종족이 섞여 산다

장소 여섯 말고 **사람이 사는 집과 소품**으로 지도를 채운다. 비율:

| 종족 | 집 수 | 생김새 |
|---|---|---|
| 인간 | 가장 많이 (6채 이상) | 목골조, 붉은 기와 (시범 v3 여관 계열) |
| 엘프 | 3채 이상 | 살아 있는 나무에 기대거나 줄기를 감싼 집, 덩굴, 둥근 창 |
| 페어리 | 5채 이상 | **무릎 높이**(사람의 0.3~0.5배)의 작은 문, 버섯·화분·찻주전자 같은 집. 무리 지어 한 구석에 |
| 돌 다루는 이들 | 3채 이상 | 낮고 두꺼운 돌집, 굴뚝, 반쯤 땅에 묻힌 모양. 대장간 근처 |

- 집은 문이 있어도 들어가지 않는다(장소가 아니다). `place`를 적지 않는다
- 소품: 나무 여럿(흔들림 자리 `sway`), 가로등(불빛 자리 `light`), 화분·통·상자·수레·울타리·덤불
- 화면 어디를 비춰도(1920×1080) **사물이 거의 없는 빈 칸이 넓게 생기지 않게.** 지도를 240×135 칸 256개로 나눴을 때 막힌 픽셀 1% 미만 칸이 **광장을 빼고 10% 아래**
- **사람이 설 빈자리**를 남긴다: 각 문 앞, 우물가, 노점 앞, 골목 어귀. NPC 30명 가까이가 다닌다

## 걸을 수 있는 곳

- **걸을 수 있는 면적 30% 이상**, 여섯 곳의 문 앞이 모두 이어져 있을 것
- **건물 뒤편은 막는다.** 이 시점에서는 건물 뒤에 선 사람의 머리가 지붕 위로 튀어나와 지붕에 선 것처럼 보인다(시범에서 확인). 건물의 지붕이 덮는 화면 영역 전체를 막고, 좌우 옆은 지나갈 수 있게
- 지도 가장자리 바깥으로는 못 나가게(코드가 벽을 친다 — 그림은 가장자리까지 자연스럽게 채운다)

## `layout.json` 형식

시범 v3의 형식을 그대로 쓰고 다음을 더한다. **좌표는 전부 1배 지도 px**(왼쪽 위 기준, y는 아래로).

```json
{
  "map_size": [3840, 2160],
  "person_height_px": 135,
  "part_scale": 2,
  "parts": [
    {
      "file": "inn.png",
      "place": "inn",
      "size": [1378, 1062],
      "foot": [960, 600],
      "pivot_in_png": [530, 1040],
      "footprint": [[x, y], ...],
      "block": [[[x, y], ...]],
      "anchors": { "door": [[x, y]], "cellar": [[x, y]], "light": [...], "smoke": [...], "sway": [...] }
    }
  ]
}
```

- `size`, `pivot_in_png`: **2배 PNG 기준** px. `foot`, `footprint`, `block`, `anchors`: **1배 지도 기준** px
- `footprint`: 사물이 바닥에 닿는 면(다각형 하나). 충돌이 된다
- `block`: 걸을 수 없게 막을 추가 다각형 목록(건물 뒤편). 없으면 빈 목록
- `anchors.door`: 장소의 문 앞 사람 자리. `place`가 있는 사물만. `cellar`는 여관의 창고 문 자리
- `place`: 장소 여섯에만 적는다. 노점 셋은 `board`가 아니라 `"stall"`
- `walkable.png`(3840×2160, 흰색 = 걸을 수 있음)도 함께 낸다. 위 다각형들과 일치해야 한다

## 단계별 납품 — 한도에 걸려도 끝난 데까지는 쓸 수 있게

`Outputs/VillagePartsFull_v1/`에 아래 순서로 만든다. **한 단계가 끝날 때마다 README의 진행표를 갱신**한다.

1. **골격** — `layout_plan.png`(지도 위에 장소·길·집 자리를 상자로 표시한 계획도) + 바닥판 `ground.png` + 여섯 장소의 주 건물. 이 단계만으로도 게임에 깔 수 있어야 한다
2. **집** — 종족 건축 (인간 → 돌 → 엘프 → 페어리 순)
3. **소품과 마감** — 나무·가로등·노점 세부·화분 등, `walkable.png`, 접지·투영 그림자를 바닥판에 굽기(시범 v3 방식)
4. **검수** — 아래 항목

## 검수

1. 바닥 어지러움 값, 판석 표본 10개의 가로·세로·비율(8/10 이상 통과), 평균 RGB, 반복 검사
2. 원형 상판 비율(우물 등) 0.45~0.55
3. 사람(135px)을 문 앞 여섯 곳과 광장에 세운 `depth_test.png` — 문 높이 대비가 보이게
4. 빈 칸 비율(광장 제외 10% 아래), 걸을 수 있는 면적, 여섯 문 앞 연결성
5. 2배 사물을 1.7배 확대 화면 크기로 잘라 본 `zoom_test.png` (여관 문 앞, 페어리 집 무리)
6. 바닥 조각 이음매를 표시한 `seams.png`와 각 조각의 확대율(1.15 이하)
7. 전체 미리보기 `VillagePartsFull_v1_preview.png`(1배 지도에 사물을 세운 모습)와 화면 크기 잘라 보기 네 장(광장, 여관, 대장간·돌집, 페어리 구석)
