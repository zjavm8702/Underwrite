# 대화 초상 수정 v1 — 학자 「안도」 다시 그리기, 엘프 코 고치기

사장님이 실제 게임 대화 화면에서 보고 판정했다. 두 가지다.

## 1. `face_scholar_relieved.png` — 깨졌다

Claude Code가 확대해서 확인한 상태:

- **얼굴이 두 겹으로 겹쳐 있다.** 감은 눈과 안경이 위에 하나, 뜬 눈과 안경이 아래에 하나 — 안경 두 개, 눈 두 쌍이 보인다
- **얼굴 오른쪽 윤곽이 계단처럼 깨졌다.** 코 자리가 잘려 나가 투명해졌다
- 표정 영역 합성(얼굴만 덮기)이 어긋난 것으로 보인다

다시 그린다. 「안도」는 긴장이 풀려 어깨가 내려가고 숨을 내쉬는 얼굴이다. 눈은 감거나 반쯤 감고, 입가는 조금 풀린다.
**같은 학자의 다른 6표정과 머리·몸·의상·조명이 완전히 같아야 한다.** 표정 영역 밖은 평상(neutral)과 픽셀 단위로 같게.

## 2. 엘프 7표정 — 코가 이상하다

- **코가 거의 그려지지 않았다.** 콧날·콧방울이 보이지 않아 얼굴 가운데가 비어 보인다
- 안경 코받침이 코가 있어야 할 자리에서 떠 있다. 안경이 얼굴에 걸려 있지 않은 것처럼 보인다

**7장 모두** 고친다(neutral, happy, anxious, angry, shocked, sad, relieved). 표정마다 따로 그리면 코 모양이 표정마다 달라진다.
평상(neutral)의 코를 먼저 고쳐 정하고, 같은 코를 나머지 6장에 똑같이 쓴다.

- 약한 오른쪽 3/4 각도에 맞는 작고 갸름한 코. 콧날의 빛과 콧방울 아래 그늘을 셀 채색으로 얌전하게
- 안경 코받침이 콧날 위에 **실제로 얹히게** 한다
- 눈·입·머리·귀·안경테 모양·장신구는 바꾸지 않는다

## 지킬 것 — 표정이 바뀔 때 얼굴이 튀면 안 된다

대화 중 표정이 바뀌면 같은 자리에서 그림만 갈아 끼운다. 얼굴 위치나 크기가 어긋나면 화면에서 얼굴이 튄다.

- `Documents/Codex/Underwrite_대화용_상반신_표정_제작기준.md`를 그대로 따른다
- 820×1080 RGBA, 파일 이름 그대로
- 같은 인물 7장 사이 알파 bbox·머리 꼭대기 y·눈선 y 편차 **10px 이하**
- 7장 겹침 PNG, 표정 영역 밖 RGBA 변경 픽셀 수(평상 대비) 기록
