# 영지 파츠 시범 v3 — 바닥만 다시: 크고 불규칙한 판석

v2 바닥을 실제 게임 화면에 깔아 보니 **너무 어지럽다.** 사장님 판정이다.
원인은 돌이 **잘고(20px) 규칙적이며**, 돌마다 외곽선과 하이라이트가 강하기 때문이다.
NPC 십여 명이 걸어 다니는 화면에서 바닥이 사람보다 먼저 눈에 들어온다.

**사물 12장, `layout.json`, 사물 배치는 v2 그대로 쓴다.** 다시 그리는 것은 `ground.png`와 `walkable.png`뿐이다.
v2 폴더의 사물 PNG와 배치표를 그대로 복사한다.

## 정해진 것 — 판석 크기 (사장님이 실제 화면에서 골랐다)

Claude Code가 크기만 다른 시험 바닥 세 가지(45 / 70 / 100px)를 Unity 화면에 깔아 비교했고, **45px로 정했다.**

- 참고 그림: `Outputs/_reference/flagstone_size_test_45px.png` — **크기와 불규칙함만** 본다.
  코드로 만든 시험본이라 질감이 밋밋하다. 질감·입체감은 이것보다 낫게 그린다
- 실제 화면 비교: `Outputs/_reference/flagstone_ingame_compare.png` (오른쪽 위가 고른 것)

| 항목 | 값 |
|---|---|
| 판석 한 장의 **가로** | **35~55px** (평균 45px, 사람 135px의 1/3) |
| 판석 한 장의 **세로** | 가로의 **0.45~0.55배** (바닥이 15도로 누워 보인다. 원형 상판 비율과 같다) |
| 모양 | **불규칙한 다각형 판석.** 크기·모양이 제각각. 벽돌처럼 줄 맞춰 쌓지 않는다 |
| 줄눈 | 가늘고 옅게 (2~3px). 판석보다 조금만 어둡게 |
| 판석 하나하나의 외곽선·하이라이트 | **약하게.** v2처럼 돌마다 진한 테두리와 밝은 윗면을 그리지 않는다 |

## 어지러움을 숫자로 — 이번 핵심

재는 법: 바닥판을 흑백으로 바꾸고, 반지름 4px 가우시안 블러를 뺀 차이의 표준편차.
(작은 무늬의 명암 대비다. 클수록 어지럽다.)

| 바닥 | 값 |
|---|---|
| v1 (회색 벽지) | 28.0 |
| v2 (어지러움) | **42.4** |
| 45px 시험본 (밋밋함) | 7.4 |
| **목표** | **12~20** |

20을 넘으면 실패다. 12 아래면 밋밋해 판석으로 안 읽힌다.

## v2에서 지킬 것 — 이건 좋았다

- **따뜻한 색.** v2 평균 RGB (187, 158, 121) 근처
- **사람이 다닌 길**: 문 앞에서 광장으로 닳아서 밝고 매끈한 길
- 가장자리·사물 밑동의 흙, 돌 틈의 풀 조금, 빠진 돌 한두 군데 — **얌전하게**
- 사물 밑동 바로 아래 짧고 짙은 **접지 그림자**(3~6px)와 오른쪽 아래로 늘어지는 그림자. 바닥판에 그린다
- 반복 무늬 0쌍 (v2와 같은 128×128 칸 검사)

## 하나 더 — 건물 뒤편

시범 화면에서 여관 **뒤편을 걷던 NPC가 지붕 위에 선 것처럼** 보였다.
앞뒤 가림은 맞게 동작하지만, 이 시점에서는 건물 뒤에 선 사람의 머리가 지붕 위로 튀어나온다.

- `walkable.png`에서 **여관 뒤편(여관 footprint 위쪽, 지붕이 덮는 화면 영역 전체)을 막는다**
- 여관 좌우 옆으로는 지나갈 수 있게 둔다
