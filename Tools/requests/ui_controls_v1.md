# 거래 화면 조작 부품 양피지화 v1

## 왜 필요한가

거래 화면의 패널·바탕은 양피지 이미지가 들어갔다(`Outputs/MarketUI_Parchment_v1` 납품분, 현재 `Assets/UI/Images/`에 적용 중). 그런데 **버튼·탭·입력칸은 아직 색만 칠한 사각형**이라 게임풍과 겉돈다. 그 세 가지를 같은 양피지 세계의 물건으로 바꾼다.

## 납품할 PNG 6장

모두 **512×192, 9-slice Border 48/48/48/48**, RGBA, 글자·숫자·기호 없음.

| 파일 | 용도 | 표현 방향 |
|---|---|---|
| `ui_button_normal.png` | 일반 버튼 바탕 | 종이 위에 살짝 돋은 면. 눌리지 않은 상태 |
| `ui_button_pressed.png` | 선택·눌린 버튼 | 잉크로 칠해 꺼진 면. 글자는 종이색으로 뒤집힌다 |
| `ui_button_disabled.png` | 비활성 버튼 | 바래고 힘이 빠진 면 |
| `ui_tab_on.png` | 선택된 탭 | 앞으로 나온 종이. 아래쪽이 본문과 이어진 느낌 |
| `ui_tab_off.png` | 선택 안 된 탭 | 뒤로 물러난 종이 |
| `ui_field.png` | 수량·지정가 입력칸 | 안으로 **파인** 자리. 눌린 것이 아니라 홈이 파여 숫자를 적는 칸 |

## 쓰이는 실제 크기

9-slice로 늘려 쓰며 `-unity-slice-scale: 0.5`를 적용한다. 즉 **원본 2px이 화면 1px**이다. 이 배율에서 뭉개지지 않을 만큼만 결을 넣는다.

| 부품 | 화면 크기 (px) |
|---|---|
| 상단 버튼 (일시정지·장 넘기기) | 폭 90~150 × 높이 40 |
| 비율 버튼 (25%·50%·75%·최대) | 폭 80 × 높이 34 |
| 탭 (매수/매도, 시장가/지정가) | 폭 180 × 높이 46 |
| 입력칸 | 폭 86 × 높이 46 |
| 주문 실행 버튼 | 폭 390 × 높이 48 |

가장 작은 34px 높이에서도 형태가 뭉개지면 안 된다. 세로로 6배 가까이 늘려 쓰므로 **위아래 테두리는 48px 안에서 끝나야 한다.**

## 색

기존 납품분과 같은 세계다. 아래는 현재 테마 토큰이다.

- 종이: `#F2E7D2` / 패널 안쪽은 이보다 조금 밝다
- 잉크(글자): `#2A2118`
- 흐린 글자: `#5B4D3E`
- 구분선: `#C9BBA2`
- 상승(빨강): `#B5323E` · 하락(파랑): `#1F56B8`

`ui_button_pressed.png`는 잉크색 면이고 그 위에 `#F7F0E2` 글자가 올라간다. 나머지는 종이색 면이고 잉크 글자가 올라간다. **매수·매도 버튼의 붉은/푸른 면은 코드에서 색으로 칠하므로 만들지 않는다.**

## 지켜야 할 것

- **글자·숫자·기호·화살표를 넣지 않는다.** 바탕만이다.
- 중앙은 거의 평면이어야 한다. 글자가 얹히는 자리다. 결과 마모는 가장자리에 둔다.
- 각 PNG의 중앙 영역에서 잉크 `#2A2118` 대비 4.5:1 이상을 확보한다. `ui_button_pressed.png`는 반대로 `#F7F0E2` 기준으로 잰다.
- 9-slice로 늘렸을 때 이음새나 장식 단절이 없어야 한다. 위 표의 실제 크기 전부로 미리보기를 떠서 확인한다.
- 글로우·드롭섀도를 넣지 않는다. 종이의 두께감은 명암으로만 낸다.

## 검수에 넣을 것

- 9-slice 미리보기 (위 5가지 실제 크기 전부)
- 여섯 장을 나란히 둔 상태 비교 이미지. 일반/선택/비활성이 한눈에 구분되는지 본다
- 중앙 대비 측정값
- 기존 `Assets/**/*.meta` 해시 변동 없음 확인
