# 영지 성벽 v1 — 지금 지도에 성벽을 두른다

`Outputs/VillagePartsFull_v1/`(영지 전체 지도, 게임에 들어가 있음)의 가장자리가 그냥 잘려 보인다. 사장님 요청으로 **성벽을 두른다.**
지도·바닥·장소는 그대로 두고 성벽 사물만 더한다. 결과는 **새 판 `Outputs/VillagePartsFull_v2/`** 로 낸다(v1은 건드리지 않는다).

판정은 **실제 게임 화면에서 어색하지 않은가**다. v1 사물과 같은 세계, 같은 시점, 같은 빛.

## 고정된 것 (v1과 같다)

| 항목 | 값 |
|---|---|
| 지도 | 3840 × 2160 px (1배). `ground.png`는 v1 것을 그대로 복사 |
| 시점 | 약 15도. 원형 상판 세로÷가로 0.45~0.55 |
| 사람 키 | 135px (1배) |
| 사물 해상도 | **2배**로 그린다(`part_scale: 2`). 좌표는 1배 지도 기준 |
| 빛 | 왼쪽 위, 한낮 중성광. 사물 원본에 접지 그림자·불빛 번짐을 그리지 않는다 |
| 장소 여섯의 문 위치 | **바꾸지 않는다** (inn 775,704 · manor 1949,637 · guild 3149,823 · smith 583,1548 · board 3013,1532 · well 1920,1224) |

## 성벽

밝은 회갈색 돌로 쌓은 영지 성벽. 군사 요새가 아니라 **작은 영지를 두른 낮고 오래된 성벽** — 이끼, 군데군데 깨진 돌, 담쟁이 조금.

| 위치 | 보이는 모습 | 높이 (1배) |
|---|---|---|
| **북쪽(위)** | 정면이 보인다 — 돌 벽면과 위의 여장(톱니) | 사람의 2.2~2.8배 (300~380px) |
| **동·서쪽(옆)** | 옆에서 본 성벽 — 위쪽 걷는 길(성벽 윗면)과 바깥쪽 벽 두께가 좁게 보이는 띠 | 띠 너비 70~100px |
| **남쪽(아래)** | 뒤에서 본 성벽 — **낮게**(사람의 0.6~0.9배). 높으면 화면 아래쪽 마을을 가린다 | 80~120px |
| 모서리 네 곳 | 둥근 **모서리 탑**. 원뿔 지붕 또는 평평한 톱니 꼭대기 | 사람의 3~3.5배 |
| **성문** | **남쪽 가운데(x 1920 근처)** 에 하나. 열린 나무 문짝이 달린 아치, 양옆 작은 문루 | 아치 높이 사람의 1.6~2배 |

- **조각으로 그린다**: 직선 조각(북·옆·남 각각 2~3가지 변형), 모서리 탑, 성문. 같은 조각을 이어 붙이되 이음매가 보이지 않게, 변형을 섞어 반복이 티 나지 않게
- 성문 바깥(지도 아래 가장자리 바깥)은 보이지 않아도 된다. 성문 아치 안쪽으로 바깥 길이 조금 보이면 좋다
- 북쪽 성벽 앞 1~2칸(사람이 설 자리)은 걸을 수 있게 둔다

## v1 사물과 겹치는 것

성벽이 들어갈 자리(지도 가장자리 안쪽 약 120~400px)에 v1 사물(나무·울타리·덤불 등)이 겹치면 **옮기거나 뺀다.**
- 건물·장소는 옮기지 않는다. 장소의 문 앞은 막지 않는다
- 옮기거나 뺀 사물을 `README.md`에 목록으로 적는다
- 성벽 안쪽의 빈자리가 넓어지면 v1에서 쓰던 소품(나무·덤불·화분)으로 자연스럽게 채운다

## 걸을 수 있는 곳

- 성벽(+ 북쪽 성벽 뒤, 옆 성벽 바깥)은 막는다. 남쪽 성벽은 그 위로 걸어 넘어가지 못하게 막는다
- **성문은 지금은 막는다**(영지 밖으로 나가는 기능이 아직 없다). 나중에 열 수 있게 성문 아치 바닥 자리를 `anchors.gate`로 적는다
- v1처럼 걸을 수 있는 면적 30% 이상, 장소 여섯·노점 셋의 문 앞이 광장과 모두 이어져 있을 것
- `walkable.png`(3840×2160, 흰색 = 걸을 수 있음)를 새로 낸다

## `layout.json`

v1 형식 그대로(`map_size`, `part_scale`, `parts[]`의 `file`·`size`·`foot`·`pivot_in_png`·`footprint`·`block`·`anchors`·`place`).
**v1 사물 전부 + 성벽 조각**을 한 파일에 담는다(옮긴 사물은 새 좌표로, 뺀 사물은 없앤다). 성벽 조각에는 `"kind": "wall"`을 적는다.
v1 PNG는 v2 폴더로 복사해 같은 이름으로 둔다(Unity 도구가 판 번호가 가장 높은 폴더 하나만 읽는다).

## 검수

1. 북·남·동·서 가장자리와 성문을 1920×1080으로 잘라 본 화면 다섯 장(사람 135px 하나씩 세워서)
2. 남쪽 성벽이 아래쪽 마을을 가리는 정도 — 남쪽 가장자리 화면에서 성벽 바로 위 사람이 가려지지 않는지
3. 걸을 수 있는 면적, 문 앞 연결성(v1과 같은 방법)
4. 성벽 조각 이음매를 표시한 `wall_seams.png`, 반복 검사
5. 옮기거나 뺀 v1 사물 목록
6. 전체 미리보기 `VillagePartsFull_v2_preview.png`

## 범위

**PNG와 layout.json까지.** `Assets/`에는 쓰지 않는다. `Outputs/VillagePartsFull_v1/`은 건드리지 않는다.
한도에 걸려도 끝난 데까지 쓸 수 있게 README에 진행표를 둔다: ① 성벽 조각 그림 → ② 배치·v1 사물 정리 → ③ walkable·검수.
