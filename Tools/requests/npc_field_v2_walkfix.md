# 영지 NPC 2차 수정 — 걷기 다리 동작 다시 그리기

`Outputs/NpcField_v2/`(걷는 용병단 단원 네 유형)를 게임에 넣어 보니 **걷기가 걷기가 아니다.** 사장님 판정 「다리가 이상하다」.

## 무엇이 틀렸나 (Claude Code가 프레임을 확대해 확인)

정상 걷기는 왼발·오른발이 번갈아 앞뒤로 나간다(닿음 → 들림 → 다른 발을 지나침 → 닿음). 지금 단원들은 **다리가 바뀌지 않는다.**
- leader·archer **S**: 한 발이 8프레임 내내 땅에 붙어 있고 다른 발만 가끔 들린다 — 절뚝임
- leader·porter **E**: 앞발이 모든 프레임에서 앞에 고정, 뒷발만 움직인다 — 미끄러짐
- archer·porter **NE**: 같은 다리가 8프레임 내내 뒤로 차올라 있다 — 한 발 뛰기
- 이전 검수는 발 위치 편차·잘림만 재서 이것을 놓쳤다

## 고치는 방법

**걷기(Walking) 프레임만 다시 그린다.** 대기(Idle)·마스크 방식·캔버스·기준점·파일 이름은 그대로.

- **주인공 걷기를 자세 기준으로 쓴다:** `Assets/Images/Characters/Protagonist/Walking/{S,SE,E,NE,N}/walk_*_00~07.png`
  - 같은 방향·같은 프레임 번호에서 **다리와 발의 위치·각도·어느 발이 앞인지를 주인공과 똑같이** 맞춘다
  - 팔 흔들기도 주인공과 같은 박자(다리와 반대)
  - 몸·옷·장비(검·활·방패·보따리)만 각 유형의 것으로. 장비가 다리와 함께 흔들리면 자연스럽다
- 단 색 마스크도 새 프레임에 맞춰 다시 낸다
- 프레임 시간은 주인공과 같게(100ms × 8)

## 검수 (꼭)

1. **발 교대 표:** 유형·방향마다 8프레임 각각 「앞발: 왼/오른, 땅에 닿은 발: 왼/오른/둘 다」를 적은 표. 주인공 같은 프레임의 값과 나란히 두고, 다른 칸이 있으면 실패
2. 유형마다 다섯 방향 걷기 띠 — 각 줄 위에 같은 방향 주인공 띠를 함께
3. 다리 부분만 확대한 띠(허리 아래) — 사람 눈으로 교대가 보이게
4. 기존 검수(알파·발밑 편차·마스크가 알파 안) 그대로

## 범위

**PNG까지.** 납품은 `Outputs/NpcField_v2_walkfix/`에 같은 폴더 구조(`{유형}/Walking/{방향}/`)와 갱신한 `timing.json`. `Outputs/NpcField_v2/`는 건드리지 않는다. `Assets/`에 쓰지 않는다.
진행표: ① leader → ② archer → ③ shield → ④ porter → ⑤ 검수.
