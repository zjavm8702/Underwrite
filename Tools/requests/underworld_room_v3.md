# 지하 방 v3 — 배치를 새로 짜고 바닥을 다시 (v2 교차 검수 반려)

v2(`Outputs/UnderworldRoom_v2/`)를 과장·대리가 따로 판정했다. 대리 결론 「데모에 넣으면 안 됨」, 과장도 같다.
**배치 문제의 절반은 과장 잘못이다** — v1 요청 때 넘긴 자리표(임시 상자 자리)를 그대로 따르게 해서 방 가운데가 비고 기둥이 떠 있었다. 이번 배치는 과장이 새로 짠 아래 표를 따른다.

## 0. 진행 순서 — 두 단계

1. **1단계(읽기 전용): 바닥 질감 무료 에셋 조사** — 상시 지시서 §2-1. 후보 목록만 보고하고 멈춘다. 그리지 않는다
2. **2단계(쓰기): 과장이 후보를 검수한 뒤** 통과한 질감을 쓰거나, 반려하면 그린다. 2단계는 따로 요청한다

### 1단계에서 찾을 것

- 지하 술 창고 바닥: **작은 판석·자갈 바닥**, 위에서 약 15도로 내려다본 시점(정면 평면 텍스처면 시점 판단을 적기)
- 판석 크기가 영지 기준(**가로 35~55px, 평균 45, 세로는 가로의 0.45~0.55**, 사람 135px 기준)으로 축소·반복 가능한지
- 비도트 일러스트풍, 낮은 채도, 표면 잔무늬 적게. 사진 텍스처·도트·카툰은 제외
- 이음매 없는 반복(seamless) 여부, 해상도, 파일 형식
- 벽(돌벽·나무 버팀목) 질감 후보가 같은 출처에 있으면 함께 적되 필수는 아니다
- 목록 항목은 §2-1 양식(이름·미리보기·라이선스 원문·확인 날짜·상업 사용·출처 표기·시점/축척/선/명암 비교). 후보가 없으면 검색한 곳과 탈락 이유

## 1. v2 판정 요약 (2단계에서 반영)

| 항목 | 판정 | 고칠 것 |
|---|---|---|
| 바닥 얼룩 | 반려 | 자주·붉은 얼룩이 **피로 읽힌다**. 붉은 계열 금지 — 흘린 술은 짙은 갈색 젖은 자국, 대비 낮게. 톱밥은 테이블 주변에만 조금 |
| 바닥 대비 | 반려 | 판석마다 명암이 강해 화면이 시끄럽다. 판석 간 명도 차를 줄이고 사람·가구가 바닥보다 먼저 읽히게 |
| 닳은 길 | 수정 | 주황 띠가 그려진 길처럼 보인다. 색을 넣지 말고 **판석이 매끈하고 조금 밝은 정도**로만 |
| 기둥 | 반려 | 방 가운데 선 기둥 셋 삭제. 기둥은 **벽 판 안**에만(벽에 붙은 버팀목) |
| 카운터 | 반려 | 세로로 긴 칸막이로 읽힌다 → **가로로 놓고, 정보상이 서는 안쪽(벽 쪽)이 보이게** |
| 계단 | 반려 | 어디로 이어지는지 불분명 → 위 벽의 문에서 왼쪽 벽을 따라 내려와 층계참에서 끝난다 |
| 칠판 | 수정 | 그림은 통과. 자리를 옮긴다(아래 표). 글자는 코드가 쓴다 — 격자만 그대로, `anchors.board_text` 칸 형식 유지 |
| 테이블·술통·상자·촛대 | 통과 | 그대로 쓰되 자리를 옮긴다 |

## 2. 새 배치 (지도 1배 좌표, 2880×1620, 왼쪽 위 원점)

방 크기·좌표 체계·`layout.json` 형식은 v2와 같다(과장 도구 `Assets/Editor/Prototype/UnderworldRoomParts.cs`가 그대로 읽는다). 바뀌는 것은 자리와 벽 모양뿐이다.

| 사물 | 자리(발밑) | 메모 |
|---|---|---|
| 위 벽 | 왼쪽 x 0~1670은 바닥 시작 y 245, 오른쪽 x 1670~2880은 y 515 (v2와 같음) | 벽 판 안에 버팀목 기둥 |
| 계단 | 위 벽 문(x 140~380) → 왼쪽 벽을 따라 남쪽으로 → 층계참 발밑 (300, 600) | 계단 양옆은 `room_block`. 문 높이는 사람의 1.2~1.3배 |
| 들어온 자리 `spawn` | (320, 690) | 층계참 바로 앞 |
| 칠판 `stock_board` | 위 벽에 건다. 가운데 x 1000, 벽 바닥 y 245 | 칠판 앞 `BoardFront`는 (1000, 340) 정도 |
| 카운터 `counter` | **가로**, 발밑 가운데 (2330, 860), 길이 약 640(x 2010~2650), 깊이 약 110 | 저울은 유지. 카운터 뒤 벽(y 515)에 술병 선반 — 벽 판 안에 |
| 정보상 `informant` | (2330, 720) | 카운터와 벽 사이(폭 약 270). 손님(주인공)은 카운터 남쪽에서 말을 건다 |
| 테이블 넷 | (880, 720) · (1340, 780) · (960, 1130) · (1430, 1190) | 한데 모은다 — 투자꾼이 칠판을 보며 앉는 자리. 다섯째 테이블은 뺀다 |
| 술통 더미 | (230, 1360) · (2700, 1240) | 둘은 다른 모양 |
| 상자 | (2560, 1460) · 왼쪽 벽 선반 (110, 1050) | 벽 쪽으로 붙여 방을 좁혀 보이게 |
| 빛 | 테이블마다 촛대, 카운터 등잔, 계단 문 옆 벽 촛대 하나 | 빛 번짐은 그리지 않는다(코드가 Light2D) |

- 다니는 길: **층계참 → 테이블 사이 → 칠판 앞**, **칠판 앞 → 카운터 앞**. 길 폭은 사람 어깨 둘 이상(약 120px) 비운다
- 빈 바닥이 넓어 보이면 벽 쪽에 짐·자루를 붙여 좁힌다. 가운데를 비우지 않는다
- 사람 앉을 자리 `anchors.seats`·`seat_ground`는 v2 형식대로 테이블마다

## 3. 분위기

- 술 창고를 개조한 **좁고 은밀한 거래장**. 벽 쪽과 구석은 어둡게, 테이블 무리 주변만 바닥 명도로 은근히 밝게
- 채도 낮게, 금속 광택 줄이기. 영지처럼 맑고 단순한 면
