# Codex 아트 작업 목록 (2026-10-17 정리)

Claude Code가 지금까지의 결정과 플레이 피드백을 모아 정리했다. **위에서부터 우선순위 순이다.**
각 항목은 걸기 전에 Claude Code가 상세 요청서(`Tools/requests/<이름>.md`)를 따로 쓴다 — 이 문서는 목록이다.
Codex 사용량이 적으니 **한 번에 하나씩**, 사장님 확인을 받고 건다.

## 공통 기준 (모든 항목)

- `Documents/Codex/Underwrite_아트_작업규칙.md`가 최상위
- **판정은 실제 게임 화면에서 어색하지 않은가.** 수치 통과만으로 끝내지 않는다
- 캐릭터는 **15도 시점**(신발 발등이 조금 보이고 어깨 윗면은 안 보임). 배경과 새 캐릭터는 여기에 맞춘다
- 사람 키 기준 **135px**(화면 1920×1080의 1/8). 문 1.2~1.3배, 2층 건물 3.5~4.5배
- 빛은 왼쪽 위, 한낮 중성광. **불빛 번짐·후광·접지 그림자는 그리지 않는다**(코드가 붙인다)
- 대화창은 화면을 덮는다 — 감정이 오가는 장면의 그림이 이 게임의 심장이다

- 지도 크기는 축척을 맞추면 커진다 — 요청서에서 장소 간격과 함께 정한다

## 2. NPC 필드 스프라이트 `npc_field_v1`

지금 영지 사람 22명은 **주인공에 색만 입힌 임시본**이다.

- 주인공과 **같은 15도 시점, 같은 캔버스, 같은 발밑 기준선**(Idle 362×724, 발 (181,13))
- 8방향 Idle 6프레임 + Walking 8프레임. 피벗은 **Center**(2026-10-17 결정)
- 첫 묶음: 주민 남녀 각 1(여관 손님·술꾼·서기 등 의상 변주), 노점상 1, **모험단 셋의 단원**(블랙무어 단 — 거칠고 짙은 갑옷 / 회색 파수대 — 회색 국경 경비 / 등불 기사단 — 등불 문장 기사) 각 1~2
- 접지 그림자는 그리지 않는다

## 5. 필드 몸짓 애니메이션 `actor_motions_v1`

코드에 자리가 이미 있다(`CharacterActor`). Animator에 상태만 추가하면 바로 쓰인다.

- **Nod**(끄덕), **Shake**(고개 젓기·놀람), **Hop**(반가움) — 지금 코드로 몸을 흔들어 대신하는 셋
- 다음 후보: Bow(인사), Wave(손 흔들기), Think(턱 괴기), Sigh(한숨)
- 우선 주인공, 8방향 중 S·SE·SW(앞쪽 셋)만 먼저 — 대화 전후에 대개 앞을 본다
- 프레임 수는 환호(Cheer)처럼 일회 재생 6~8
