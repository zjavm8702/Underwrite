# 엘프 코 수정 v2 — 들창코처럼 보인다

v1에서 코가 생겼다. 그런데 사장님 판정: **"너무 들창코 같다."**
Claude Code가 확대해 확인한 원인:

- 코끝 아래에 **넓게 휜 선과 그늘**이 그려져, 아래에서 올려다본 코끝(콧구멍 쪽)으로 읽힌다
- **콧날이 짧고 코끝이 넓다.** 코끝이 위로 들린 모양이 된다
- 엘프는 "가늘고 성숙한 체형"(기획서 §17)이다. 지금 코는 어리고 동글동글한 인상이다

비교 그림: `Outputs/PortraitFix_v1/before_after.png`

## 고칠 모양

- **콧날을 길고 곧게.** 눈썹 사이 아래에서 시작해 거의 곧게 내려온다. 약한 오른쪽 3/4 각도이므로 콧날은 얼굴 오른쪽(화면 오른쪽) 볼 쪽에 가늘게 한 줄로 보인다
- **코끝은 작고, 아래·앞을 향한다.** 위로 들리지 않는다
- **콧구멍을 그리지 않는다.** 코끝 아래 그늘은 아주 작고 옅게, 짧은 한 획 정도
- 코끝에서 입까지(인중) 거리는 v1보다 **조금 더 길게** — 코가 짧아 보이지 않게
- 셀 채색 계열로 얌전하게. 콧날 빛은 가늘게
- 안경 코받침은 **콧날 위**에 얹힌다(v1에서 맞춘 것 유지)

참고할 인상: 성숙한 여성 캐릭터의 갸름하고 곧은 콧날. 학자·검사 초상과 같은 화풍의 코 그리는 방식.

## 지킬 것 — v1과 같다

- `face_elf_*.png` **7장 모두**, 평상(neutral)의 코를 먼저 정하고 같은 코를 나머지 6장에 똑같이
- 코 영역 밖은 지금 PNG(v1 결과)와 픽셀 단위로 같게 — 눈·입·머리·안경테·장신구 불변
- 820×1080 RGBA, 파일 이름 그대로, PNG만 교체, `.meta` 유지(해시 비교)
- 같은 인물 7장 사이 알파 bbox·머리 꼭대기 편차 0, 눈선은 기존 그대로
