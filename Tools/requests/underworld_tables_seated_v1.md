# 지하 방 — 사람이 앉은 테이블을 한 장으로 (사장님 10/19)

사장님 판정: 「지하방 사람들 지금 완전 위치, 몸이 하나도 안 맞는다. 그냥 의자에 앉아 있는 채로 그려 달라.」
v2(`Outputs/UnderworldPeople_v2/`)는 사람을 부품으로 쪼개 의자와 따로 맞췄더니, 게임 화면에서 사람이 **의자 옆 허공에** 앉고 방석은 비었다
(`Tools/requests/underworld_tables_seated_v1_refs/ingame_wrong.png`). 부품 방식은 과장의 잘못된 요청이었다.

## 그릴 것 — 테이블 그림을 사람이 앉은 채로 다시

지금 방의 테이블 파츠(`Outputs/UnderworldRoom_v6/`의 `table_round_a~d.png`, 배치표 `table_1~4`)를 **같은 캔버스·같은 피봇**으로, 의자에 사람이 실제로 앉은 그림으로 다시 그린다. 테이블·의자·사람이 한 그림이다.

| 배치표 | 그림 | 앉을 사람(v2와 같은 사람·옷·얼굴) |
|---|---|---|
| table_1 | table_round_a | 왼쪽 의자 Noble(몰락한 귀족), 오른쪽 의자 Merchant(뚱뚱한 상인) |
| table_2 | table_round_b | 왼쪽 의자 Gambler(늙은 도박꾼) |
| table_3 | table_round_c | 왼쪽 의자 Mercenary(젊은 용병 출신) |
| table_4 | table_round_d | 오른쪽 의자 HoodedWoman(두건 쓴 여자) |

- 사람은 **방석 위에** 엉덩이, **바닥에** 발. 몸은 테이블 쪽을 본다(카드·잔을 쥔 손이 탁자 위나 앞)
- 축척은 주인공(서면 135px)과 같은 세계 — 앉은 키는 서 있는 키의 약 0.7
- 빈 의자는 그대로 빈 의자
- **움직임 프레임은 그리지 않는다** — 한 장(정지). 숨쉬기는 코드가 아주 살짝 준다
- 이름은 `table_round_a_seated.png` 식으로 새 파일. 원래 파일은 덮지 않는다

## 지킬 것

- 캔버스 크기·피봇·발밑이 원래 테이블 PNG와 같아야 한다(배치표 좌표를 바꾸지 않는다). 테이블·의자 픽셀은 사람이 가리는 곳 말고는 그대로
- 그림체·선·명암은 지금 방 사물과 v2 사람과 같게. 사람이 의자보다 선명하거나 흐려 보이지 않게
- 알파 잡성분 0, 숨은 RGB 0, 캔버스 접촉 0
