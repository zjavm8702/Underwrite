# 거래 화면 아이콘 v1

## 왜 필요한가

지금 화면의 기호는 전부 유니코드 글자다. ▲ ▼ ▸ ▾ ✕ 를 폰트로 찍고 있어서 양피지 세계와 겉돌고, 크기와 두께가 폰트에 끌려다닌다. 손으로 그은 기호로 바꾼다.

## 납품할 PNG 10장

모두 **64×64, RGBA, 단색 실루엣**. 색은 코드에서 칠하므로 **흰색 한 가지로만** 그리고 알파로 형태를 낸다. 회색조 음영을 넣지 않는다.

| 파일 | 뜻 | 쓰이는 곳 |
|---|---|---|
| `icon_rise.png` | 오름 | 등락률 앞. 지금 ▲ |
| `icon_fall.png` | 내림 | 등락률 앞. 지금 ▼ |
| `icon_flat.png` | 보합 | 변동 없음. 지금은 기호가 없다 |
| `icon_expand.png` | 펼침 | 하단 띠 손잡이. 지금 ▾ |
| `icon_collapse.png` | 접힘 | 하단 띠 손잡이. 지금 ▸ |
| `icon_cancel.png` | 취소 | 대기 주문 취소 단추 |
| `icon_star_on.png` | 즐겨찾기 켜짐 | 종목 목록 (아직 기능 없음, 미리 만든다) |
| `icon_star_off.png` | 즐겨찾기 꺼짐 | 종목 목록 |
| `icon_locked.png` | 잠김 | 보유가 없어 못 파는 수량칸 |
| `icon_warning.png` | 경고 | 상장 폐지 예고가 걸린 종목 |

## 실제 크기

화면에서 **16~24px**로 쓴다. 64×64 원본이 1/3로 줄어든다. 그 크기에서 형태가 무너지면 안 되므로 **획을 굵게, 내부 구멍을 크게** 잡는다. 가는 선 한 가닥으로 이루어진 모양은 피한다.

## 표현 방향

- 깃펜으로 장부에 그은 기호다. 기하학적으로 완벽한 삼각형이 아니라 **손으로 그은 흔적**이 남아야 한다
- 다만 읽기가 먼저다. 흔들림은 형태를 알아보는 데 방해되지 않을 만큼만
- 오름·내림은 서로 **뒤집은 모양이 아니어도 된다.** 오름은 위로 뻗는 기세, 내림은 아래로 떨어지는 기세로 달리 그려도 좋다
- 즐겨찾기 켜짐·꺼짐은 **채움과 테두리**로 가른다. 꺼짐은 속이 빈 별이다
- 경고는 느낌표가 아니어도 된다. 봉인이 떨어진 표식 같은 것도 좋다

## 지켜야 할 것

- **글자를 넣지 않는다.** 기호만이다
- 흰색(`#FFFFFF`) 단색 + 알파. 색을 칠하지 않는다
- 64×64 안에서 상하좌우 **4px 이상 여백**을 둔다. 꽉 채우면 나란히 놓을 때 서로 붙어 보인다
- 알파 가장자리는 부드럽게. 16px로 줄였을 때 계단이 보이면 안 된다
- 열 장의 **시각적 무게를 맞춘다.** 한 아이콘만 유난히 크거나 진하면 줄에서 튄다

## 검수에 넣을 것

- 열 장을 16px·20px·24px로 줄여 나란히 놓은 비교 이미지. 그 크기에서 형태가 읽히는지 본다
- 잉크색(`#2A2118`)과 종이색(`#F2E7D2`) 두 바탕에 각각 올린 미리보기
- 각 아이콘이 차지하는 알파 면적 비율. 열 장이 서로 크게 어긋나지 않아야 한다
- 기존 `Assets/**/*.meta` 해시 변동 없음 확인
