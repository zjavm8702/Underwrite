# 영지 NPC 1차 — 한자리에 선 사람들과 그들이 하는 일

지금 영지 사람은 **주인공 그림에 색만 입힌 임시본**이다. 1차로 **한자리에 서서 일하는 사람 열 명**을 그린다.
걷는 용병단 단원(8방향)은 2차다 — 이번에 그리지 않는다.

판정은 **실제 게임 화면에서 어색하지 않은가**다. 영지 지도(`Outputs/VillagePartsFull_v1/`)와 주인공 옆에 세웠을 때 같은 세계 사람이어야 한다.

## A. 장소 주인 다섯의 대화 초상 — 옷만 주민 옷으로 다시

`Assets/UI/Images/Faces/face_folk_{innkeeper,archivist,smith,steward,broker}_{neutral,anxious,shocked,happy}.png` (20장)는
처음 용병단 초상으로 그려 **갑옷 차림**이다. 영지 주민(장소 주인)으로 쓰려니 옷이 맞지 않는다.

- **얼굴은 재활용한다.** 머리·얼굴 영역 픽셀은 그대로 두고 **목 아래 옷만** 다시 그린다. 표정 넷의 얼굴은 손대지 않는다
- 재활용이 어려운 사람(두건이 얼굴에 걸친 여관 주인 등)은 이유를 적고 머리 모양 쪽만 최소로 고친다
- 규격은 `Documents/Codex/Underwrite_대화용_상반신_표정_제작기준.md` 그대로(820×1080 RGBA, 상반신, 약한 오른쪽 3/4)
- 같은 사람 4장 사이 몸·옷·알파는 완전히 같게(얼굴 영역만 다르다)

| 파일 | 사람 | 새 옷 |
|---|---|---|
| `innkeeper` | 여관 주인 (40대 여성, 잿빛 머리) | 소매 걷은 리넨 셔츠, 앞치마, 허리에 행주. 두건은 벗거나 머릿수건으로 |
| `archivist` | 길드 기록 담당 (흉터 있는 노인) | 짙은 남색 서기 로브, 잉크 묻은 소매, 목에 안경줄 |
| `smith` | 대장장이 (검은 수염) | 맨팔, 두꺼운 가죽 앞치마, 그을린 셔츠 |
| `steward` | 영주관 집사 (금발) | 단정한 긴 코트와 조끼, 영주 문장 배지 |
| `broker` | 게시판 앞 중개인 (밤색 단발 여성) | 여행용 망토 없는 평상복, 어깨 가방, 벽보 뭉치 |

**용병단 시절의 갑옷 초상 20장은 지우지 않는다** — 나중에 용병 인물로 쓸 수 있다. 새 초상은 납품 폴더에만 둔다.

## B. 필드 스프라이트 열 명

### 규격 (주인공과 같다)

- 프레임 **362×724px**, 발밑 기준점 **(181, 13)**(Unity 아래쪽 좌표, PNG로는 위에서 711px). `Assets/Images/Characters/Protagonist/Idle`과 같은 캔버스
- 시점 **15도**(신발 발등이 조금 보이고 어깨 윗면은 안 보임), 빛 왼쪽 위, **접지 그림자 없음**
- 키는 주인공과 같은 축척으로(사람마다 키 차이는 자연스럽게 ±8%)
- **방향은 정면(S) 하나만.** 한자리에 서서 일하므로 다른 방향은 필요 없다
- 알파 깔끔하게(분리 잔점 0, 숨은 RGB 0, 캔버스 닿음 0)

### 사람마다 세 동작

| 동작 | 폴더 | 프레임 | 설명 |
|---|---|---|---|
| 대기 | `Idle` | 6 | 숨쉬기·눈 깜빡임. 주인공 Idle과 같은 결 |
| 일 | `Work` | 6~8, 반복 | 아래 표의 하는 일. 이어 붙여 돌려도 튀지 않게 |
| 건네기 | `Give` | 6, 한 번 | 손에 든 것을 **화면 오른쪽 아래(주인공 쪽)로 내밀었다가** 거둔다. 주인공이 정보를 사거나 일을 마칠 때 튼다 |

| 폴더 이름 | 사람 | 일(Work) | 건네는 것(Give) |
|---|---|---|---|
| `innkeeper` | 여관 주인 | 행주로 잔을 닦는다 | 술잔 |
| `archivist` | 길드 기록 담당 | 작은 서판에 깃펜으로 적는다 | 접은 기록 한 장 |
| `smith` | 대장장이 | **모루에 망치질** — 내려칠 때 몸이 실리게. 모루는 그림에 함께 그린다(작게, 발 앞) | 쪽지 |
| `apprentice` | 견습 대장장이 | 숫돌에 날을 간다(숫돌 함께) | 동전 주머니 |
| `steward` | 영주관 집사 | 서류 다발을 넘긴다 | 봉인한 서신 |
| `guard` | 영주관 경비 | 창을 세우고 서 있다가 가끔 하품 | (건네기 대신 고개 끄덕임) |
| `broker` | 게시판 앞 중개인 | 벽보 한 장을 펴서 들어 보인다 | 벽보 |
| `vendor_fruit` | 과일 장수 | 손짓하며 부른다 | 사과 |
| `vendor_cloth` | 천 장수 | 천을 펼쳐 보인다 | 천 한 필 |
| `vendor_goods` | 잡화 장수 | 손짓하며 부른다 | 밧줄 묶음 |

- 장소 주인 다섯(innkeeper·archivist·smith·steward·broker)은 **A의 새 초상과 같은 사람으로 보여야 한다** — 머리색·머리 모양·옷 색이 맞게
- 나머지 다섯은 초상이 없다. 영지 그림과 어울리는 평범한 주민

### 파일

`Outputs/NpcField_v1/{폴더 이름}/{Idle,Work,Give}/S_00.png …` 프레임마다 한 장. 동작마다 프레임별 재생 시간(ms)을 `timing.json`에 적는다.
Unity로 들이는 것(스프라이트·Animator)은 Claude Code가 한다.
