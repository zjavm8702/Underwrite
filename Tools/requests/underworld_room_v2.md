v1(`Outputs/UnderworldRoom_v1/`)을 과장·대리가 따로 판정했고 결론이 같았다. **v1의 layout.json 형식·좌표 체계·사물 자리는 그대로 유지**하고 아래만 고친다.
납품 폴더 `Outputs/UnderworldRoom_v2/`(v1에서 통과한 PNG는 그대로 복사해 한 벌로 완결). 과장이 이미 들이는 도구(`Assets/Editor/Prototype/UnderworldRoomParts.cs`)를 만들어 두었다 — 형식이 같아야 한다.

## 판정 요약

| 사물 | 판정 | 고칠 것 |
|---|---|---|
| 바닥판 | **반려** | 판석이 가로 160~320px — 영지 기준 **35~55px**(평균 45, 세로는 가로의 0.45~0.55)의 3~9배다. 사람(135px)이 거대한 석판 위의 모형처럼 보인다. **영지 시범 v3 바닥과 같은 판석 크기**로 다시. 빈 바닥이 넓고 고르게 밝아 「에셋 전시판」으로 보인다 → 바닥에 닳은 길(계단 → 테이블 → 칠판·카운터), 얼룩·흘린 술·톱밥, 벽 쪽 그늘을 넣어 **쓰는 공간**으로 |
| 기둥 | **반려** | 천장 없이 끊긴 반쪽 아치가 방 가운데 서 있다. **벽에 붙은 기둥·버팀 들보**로 바꾸거나(벽 판 안에 그려도 된다), 세운다면 천장 들보까지 이어지는 완전한 나무 기둥(위는 화면 밖으로 잘림)으로 |
| 계단 | **반려** | 바닥 위에 놓인 작은 계단 모형처럼 보인다. **왼쪽 벽 또는 위 벽에서 내려오는** 계단으로 — 벽 판의 문/구멍과 이어지고, 위층(창고)으로 올라가는 게 읽혀야 한다. 사람 대비 문 높이 1.2~1.3배 |
| 테이블 A·B | 수정 | 의자·종이·동전 배열이 똑같이 반복된다 → 테이블마다 위에 놓인 것을 다르게(카드, 장부, 잔, 빈 상), 의자 하나는 빠지거나 돌아가 있게. 목재·천의 잔무늬 줄이기 |
| 카운터 | 수정 | 금장·광택이 과하다 → 검은 나무 + 녹슨 놋쇠 조금. 위의 저울은 유지 |
| 술통 | 수정 | 같은 다섯 더미가 두 번 → 두 더미를 다른 모양으로(넘어진 통 하나, 높이 다르게) |
| 칠판 · 상자 · 촛대·등잔 | 통과 | 그대로 |

## 분위기 (공통)

- **방 전체를 한 단계 어둡게**, 특히 벽 쪽과 구석. 가운데 테이블 주변만 은근히 밝게(빛 번짐은 그리지 않는다 — 코드가 촛불 빛을 얹는다. 바닥 자체의 명암 차로)
- 표면 질감과 금속 광택을 줄여 **영지처럼 맑고 단순한 면**으로. 지하라 채도는 낮게
- 「넓고 정돈된 석조 홀」이 아니라 **술 창고를 개조한 좁고 은밀한 거래장**. 방 크기(2880×1620)는 유지하되 벽 쪽에 쌓인 짐·선반으로 공간을 좁혀 보이게 해도 된다(막힌 곳은 `block`에)
