# 영지 파츠 시범 v1 — PNG 납품 시안

제작·수치·합성 검수 완료. 사용자 시각 승인 전 시안이다. 전체 영지 v3의 승인된 표준으로 확정하지 않는다. 작성일 2026-10-17.

## 납품 범위

- 최종 정적 파츠12장(여관1·나무2·가로등2·탁자/의자2·술통2·화분3), 불투명 바닥1장, 이진 마스크1장. 1920×1080 한 블록.
- Assets·Unity 에셋에 쓰지 않았다. 연기·등불·나무 흔들림 그림이나 새 입력을 만들지 않았다.
- 모든 원화는 내장 image_gen으로 제작. 코드 작업은 알파 정리·축소·생성 포장 텍스처 반복·그림자 투영·합성·마스크·검증이다. 술통 도형 가이드는 시점 입력이며 최종 원화는 이미지 도구가 다시 그렸다.
- 정적 환경으로 방향/프레임 시퀀스와 재생 시간은 해당 없다. 캐릭터8방향 애니메이션 완료 범위와 혼동하지 않는다.

## 알파와 재조립 검증

- 알파32 미만 제거, 완전 투명 RGB=0. 알파240 이상을 불투명으로 정리하고 2px 이상 내부의 남은 반투명 픽셀을 불투명화해 가장자리만 좁은 AA를 남겼다. 임계값을 높여 실루엣을 지우지 않았다.
- 축소 전12px 이하·축소 후2px 이하의 비의도 잡성분만 제거했다. 분리된 table_b의 의자2개는 보존했다.
- 최종 파츠12장: 비의도 분리 성분0개, 숨은RGB0px, 알파1–31 0px, 캔버스 접촉0px, 내부2px 초과 반투명0px. table_b는 의도한 탁자1+의자2=3성분, 나머지11장은1성분.
- 검은/밝은 배경 edge_review.png와 최종 해상도 원본을 확인했다. 나뭇잎/가지·등주 장식·화분 윤곽의 눈에 띄는 잘림과 색 번짐 없음.
- assembled.png는 layout.json대로 원배율 재조립. 경계 확대에서 바닥 구멍/이전 사물 실루엣 없음. 사물을 숨기면 남는 고정 그림자는 요청된 의도다.
- ground/walkable 및 합성 전체는 불투명이며 사방 캔버스 접촉은 정상이다. person_135와 door_detail 등 검수 크롭의 접촉은 의도된 trim/크롭으로 실제 파츠 잘림과 구분한다.

## 기록·재현

- generation_prompts.json: 전체 프롬프트·도구·출력 원본 경로. recorded_utc는 기록 시간이며 정확한 요청 시작 시간은 보장하지 않는다. sources/generation_history 파일 mtime에 보관 복사 시각이 있다.
- sources/: 선택 원본·기각 원본·시점 가이드·지정 주인공 원본.
- before.json: 작업 전메타522개 및 accepted v2 해시. verification.json: 최신 수치. processing.json: bbox·배율·가림. staging.json: 최종 배치/해시 명세.
- build.mjs → inspect.mjs → verify.mjs 순서로 이 폴더에서 Node 실행. build는 Outputs만 재생성한다. finalize.mjs는 기록 작성이며 Assets에 쓰지 않는다.
- Documents/Codex/Underwrite_영지_그림배경_제작기준.md에 이번 파츠/135px 축척/좌표/알파 함정을 최신 시범 기준으로 추가했다.

## 미해결·주의

- 사용자 시각 승인 전 시안. 전경의 바닥 반복 패턴과 전체 영지 확장 시 밀도는 이번 한 블록의 승인 항목이다.
- 기존 영지 문서의 통짜 그림/지붕까지 막는 마스크/큰 판석 기준은 이번 최신 요청의 분리 파츠·footprint 전용·17–23px 돌로 대체한다. 과거 단락은 이력이다.
- 기존 메타522개 유지, 변경0개, 삭제0개. 작업 중 외부 프로세스 신규 메타25개가 관찰됐다. 이 작업은 Assets·씬·스크립트를 쓰거나 원복하지 않았다.
- 외부 Assets 복사본과 현재 Outputs의 해시가 다른 파일: ground.png, tree_a.png, lamp_b.png, barrel_a.png, barrel_b.png, pot_a.png. external_assets_readonly_comparison.json에 시점과 해시를 기록했다. Claude Code는 staging.json의 최종본을 기준으로 동기화/연결해야 한다. Unity 연결은 이번 요청 범위 밖이다.
