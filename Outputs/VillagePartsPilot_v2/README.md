# VillagePartsPilot v2 — 바닥·술통 시안

PNG 제작·검수 완료, 실제 Unity 게임 화면의 시각 승인 전 시안. 납품 범위는 이 폴더이며 Assets/ 및 Unity 연결에는 쓰지 않았다. 정적 환경으로 방향별 프레임·반복·재생 시간은 해당 없다.

## 적용 내용

- 승인 사물 10장(inn, tree_a/b, lamp_a/b, table_a/b, pot_a/b/c)은 v1 원본과 SHA-256이 모두 동일하다.
- 술통 2장은 내장 image_gen으로 다시 그렸다. 기존 캔버스 72×91, 69×88과 이름을 유지했다. 실제 실루엣 높이는75,72px다.
- 바닥은 독립 생성 구역4개를 각1회 연결한 중간 시안에서 전체 화면을 다시 그려 일관성을 맞추고 돌 밀도를 수정했다. 최종 sources/groundUniform.png 전체1장을1920×1080으로 한 번 보간했다. 최종 타일링·패치 복제·반전은 없다. 생성 원본1672×941이므로 네이티브1920 원화는 아니다.
- 따뜻한 베이지·황토 석재, 문 앞에서 아래 광장으로 이어지는 밝게 닳은 길, 가장자리 흙·작은 풀, 빠진 돌·금·마른 웅덩이 흔적을 넣었다. 소품이나 사람은 바닥 원본에 없다.
- 왼쪽 위 광원으로 오른쪽 아래로 투영하는 긴 그림자와 별개로, 사물 각 열의 실제 가장 낮은 불투명 픽셀을 따라5px 접지 그림자를 ground.png에 구웠다. 기단 바닥선에도 같은 방식으로 짙은 틈을 연결했다. 사물 PNG에는 그림자를 추가하지 않았다.
- layout.json은 v1과 동일 형식이며 술통2개의 foot·pivot_in_png·footprint 여섯 필드만 바뀌었다. 술통은 문 왼쪽 기단에 붙어 있고 lamp_a와 화면상 겹치지 않는다.
- walkable.png는 흰255/검정0의 불투명 이진 마스크다. footprint만 막으며 나무 수관·지붕·그림자는 막지 않는다.

## 검사 결과

- 알파32 기준: 납품 사물12장 모두 예상 연결 성분 일치, 예기치 않은 분리 성분0개. table_b는 탁자와 분리된 의자2개의 의도된3성분이다. 숨은RGB0px, 알파1~31 잔점0px, 사물 캔버스 접촉0px. 바닥·마스크의 사방 접촉은 의도된 full-bleed다. edge_review.png에서 검정/밝은 배경 모두 육안 확인했다.
- 반복 검사:128×128 완전 칸120개 + 맨 아래128×56칸15개. 같은 크기의 모든7,245쌍을 비교했다. RGB byte 절대차 평균 MAE≤1.0을 근접 동일로 정의했다. ground.png와 그림자 전 ground_unshadowed.png 모두 정확 동일0쌍·근접 동일0쌍이다. 누적 차이가 기준을 넘으면 조기 종료해 불일치를 증명하며, 기록된 최소값은 실제 최소 MAE가 아닌 보수적 하한이다. 이 검사는 격자 칸의 픽셀 반복 검사이며 모든 이동·회전 패턴의 유사성을 증명하는 검사는 아니다.
- 색 평균(알파 가중 sRGB): 바닥 RGB(187.388,158.138,121.444), 그림자 전(188.819,159.353,122.432). 사물12장 통합 RGB(142.770,124.548,86.934). 사물별 RGB는 verification.json. 무채색 바닥은 아니다. RGB 평균만으로 물리적 광원 색온도를 산출한 것은 아니다.
- 술통 뚜껑 수평면: A0.47776/B0.47776. 원본 수평면 경계 [219,145]–[916,478], 폭697·깊이333, 수직 테두리 제외. 수동 경계 약3px 오차. 균일 비율 축소하여 최종에도 비율을 유지한다.
- 돌 표본10개:17,20,19,18,22,19,23,18,20,20px. 줄눈을 제외한 밝은 돌 면의 수평 폭이며 표본 위치·측정선은 verification.json과 stone_measurements.png에 있다. 모든 개별 돌의 전수 분할이 아니며 작은 메움돌이나 합쳐 보이는 불규칙 형태는 표본 범위 밖에 남는다.
- 마스크 footprint 불일치0px, 값0/255만 사용, 막힌 면적33,791px.
- v1 동일 다섯 자리: 문 앞(971,627), 가로등 뒤(668,784), 가로등 앞(1390,869), 나무 뒤(418,682), 탁자 옆(940,816). 135px 캐릭터와 foot-Y 정렬로 합성했다. 가려진 캐릭터 픽셀0/906/0/2307/0으로 기존 가림 구도를 유지한다. 정적 합성 검사이며 실제 Unity 재생 검사는 하지 않았다.

## 보존과 주의

기존 메타547개 모두 SHA-256 유지, 변경0·삭제0. 작업 도중 Assets/Scripts/Data/VillageQuest.cs.meta와 Assets/Scripts/UI/DialogueChoice.cs.meta가 추가된 것을 관측했다. 이 작업의 쓰기 대상이 아니며 별도 변경을 되돌리지 않았다.

v1 루트42개 파일의 작업 전 해시와 대조했을 때 PNG 및 layout 등40개가 같고 generation_prompts.json·verification.json2개는 작업 도중 달라졌다. 이 작업은 v1에 쓰는 코드를 실행하지 않았으며, 병행 변경으로 관측한 두 기록을 원복하지 않았다. 원래 해시는 before.json에 남겼다.

PNG까지라는 이번 명시 범위를 적용한다. 일반 캐릭터 애니메이션의 Unity 완료 범위는 정적 환경 파츠인 이번 작업에 적용하지 않는다. 기존 영지 지도 문서의3840×2160 단일 배경·대형 판석·보수적 전체 장애물 기준도 이번1920×1080 파츠 요청에 적용하지 않는다. 상시 지시서 자체는 수정하지 않았다.

실제 게임 화면의 어색함 여부는 시각 승인 대기다. 돌 표본 수치 통과를 모든 불규칙 돌의 크기 고정이나 최종 시각 승인으로 해석하지 않는다. 생성 원본의 일부 부드러운 가장자리는 남아 있다.

## 재현·기록
