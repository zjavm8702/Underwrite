## 납품 및 경로 충돌

요청 경로 Outputs/VillageGround_v2에 작업했으나 다른 작업이 파일을 반복 교체하고 six_places를 previous_records/six_places로 이동했다. 덮어쓰기 경합을 피하려고 현재 폴더에 이번 결과를 보존했다. 지정 경로 최종 교체는 보류했다. 이전 결과는 삭제/원복하지 않았다.

- village_ground.png / village_walkable.png: 각각3840×2160 불투명RGBA. PNG 피봇/PPU 설정 없음. 원본1672×941을 전체 bilinear 확대; 네이티브4K 세부 아님.
- 마스크는 흰색255 통행, 검정0 장애물. 그림의 화면 투영 건물·수관까지 보수적으로 막은 수동 다각형이며 자동 실루엣 추출이 아니다. 실제 발밑 충돌보다 넓게 막힐 수 있다. 계단과 문 앞 통행 공간은 열었다. 소품/통/상자 추가 제외 후 최종 검사.
