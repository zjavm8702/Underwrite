# PortraitFaces v1 — 대화용 상반신 표정 시안

셀라·브란 각 7표정, 최종 PNG 14장 제작·배치·수치 검수 완료. 사용자 시각 승인 전 시안이다. 전신을 자르지 않고 기본 제공 image_gen으로 새 상반신 2장과 표정 편집 12장, 셀라 귀걸이 보완 1장을 제작했다. CLI/API 대체 생성은 사용하지 않았다.

## 최종 파일과 범위

이 폴더 바로 아래 face_sella_*.png 7장, face_brann_*.png 7장만 납품용이다. 820×1080 RGBA. Unity 피봇·PPU는 미설정이며 공통 캔버스를 유지한다. sources/ 및 aligned/는 원본·중간 자료다. Assets/에는 쓰지 않았고 Library·Clip·Animator·Blend Tree 연결도 하지 않았다. 정지 표정이므로 8방향·재생 시간은 해당 없다.

표정/미리보기 열 순서: neutral(평상), happy(기쁨), anxious(불안), angry(분노), shocked(놀람), sad(슬픔), relieved(안도).

## 검수 결과

- 14장 모두 8연결 성분 1개. 본체 분리 잔점 0, 숨은 RGB 0, 알파 1~31 픽셀 0, 캔버스 접촉 0.
- 인물별 7장 전체 알파와 얼굴 합성 영역 밖 RGBA는 평상과 완전히 동일(차이 0픽셀). 옷·머리 외곽·턱·명암·상반신 자세 고정.
- 머리 꼭대기 최대-최소 편차: 셀라 0px, 브란 0px.
- 눈선 검출 기준 편차: 셀라 가까운 눈 5.5px / 먼 눈 7.5px / 평균 6px, 브란 4px / 1px / 평균 2px. 모두 10px 이내.
- 흰색 후보 최대 비율: 셀라 0.002938%, 브란 0.688817%. 분모는 알파≥200 픽셀 수. 알파≥200이고 RGB 모두≥244, max-min≤10을 후보로 세었다. 흰 의상·눈 흰자·치아·갑옷 반사는 보존했다.
- 기존 Assets 메타 472개 해시 유지, 변경·삭제 0개. 작업 중 외부 신규 Scripts/Global/SceneRoutes.cs.meta 1개가 관찰됐다. 본 작업은 Assets에 쓰지 않았다.
- 정지 표정 14장을 이름·감정·인물과 전수 대조하고, 어두운/밝은/여관 배경과 원본 전신 비교를 육안 확인했다. Unity 재생 검증은 범위 밖이다. review.html의 700ms 교체는 검수용이며 브라우저 실행 검증은 수행하지 않았다.

눈선 측정은 고정 검출창 안의 어두운 눈선·홍채 bbox 중앙 y다. 감은 눈은 눈꺼풀 선이므로 표정에 따른 변화도 포함한다. 해부학적 랜드마크 측정과 동일하지 않다. 조건·검출창은 verification.json과 제작 기준 문서, 눈 검출창·중앙선 표식은 previews/*_eye_measurement.png에 남겼다. 실제 눈·코·턱과 겹침 그림도 함께 검수했다.

## 제작과 보존

기본 상반신 원본 전체를 760×802로 환산하여 공통 캔버스 (30,60)에 배치했다. 생성된 표정은 공통 캔버스로 환산한 뒤, 커진 셀라 놀람/브란 분노를 평상 원화의 안정된 부위에 맞추어 정렬했다. 표정은 생성된 실제 작화를 사용하고, 얼굴 합성 마스크 밖은 평상 원화를 그대로 사용했다. 마스크 경계 10px를 부드럽게 합성했다. 얼굴의 새로운 눈·입·표정은 코드로 그리지 않았다.

셀라 원본의 가는 은색 드롭 귀걸이가 기본 생성본에서 빠져 원본 참조와 함께 이미지 도구로 보완했다. 해당 장식 영역은 7장에 똑같이 합성했다. 어두운/밝은/여관 배경에서 머리카락·목 사이 갇힌 흰 영역과 헤일로를 확인했다. 알파 32 미만만 제거하고 분리 성분 및 숨은 RGB를 정리했다. 넓은 내부는 불투명으로 정리했으며 가장자리 안티앨리어싱은 보존했다.

원본·최종 해시·시간은 generation_sources.json, before.json, after.json, verification.json. 전체 프롬프트 15개는 generation_prompts.json. 정렬 수치는 alignment_transforms.json, 좌표 CSV는 alignment_table.csv, 배치 계획/최종 파일은 staging.json. 합성 마스크·보정·알파 정리 코드는 이 폴더의 mjs 파일에 보관했다.

제작 기준 신규 문서: Documents/Codex/Underwrite_대화용_상반신_표정_제작기준.md. 캔버스·좌표·표정 목록·검수법을 기록했다. 상위 아트 규칙 및 기획서는 수정하지 않았다. 상위 문서의 애니메이션 연결 완료 규칙은 이번 정지 초상화 PNG 요청과 충돌하지 않는다.

## 미해결·주의

사용자 시각 승인 전이다. 같은 사람으로 읽히는 외형·표정 강도·실제 공용 대화상자에서의 크기는 사용자 확인이 남았다. 게임용 입력·표정 선택·전환 조건·Assets 적용은 이번 작업에 포함하지 않았다. 두 인물 확인 후 나머지 인물로 확대한다.

재현 순서: rebuild.mjs → build-previews.mjs → verify-final.mjs. rebuild는 기록된 생성·정렬본에서 최종 14장을 다시 조립하며 Assets에는 쓰지 않는다. PortraitFaces_preview.png는 위 셀라/아래 브란의 전체 14장 미리보기다.
