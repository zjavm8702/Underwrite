# 주인공 8방향 Idle v1

비도트 2D 주인공의 8방향 대기 애니메이션 시안. 기존 정면 Idle에 7방향을 추가했다.

## 파일

- `Idle_8directions_preview.png`: 8방향 동시 재생 APNG.
- `Idle_8directions_contact.png`: 방향 확인용 정지 이미지.
- 방향별 폴더: 6프레임 스프라이트 시트, 개별 PNG, 반복 APNG.
- Unity 프로젝트: `Assets/Images/Characters/Protagonist/Idle8_v1` 아래 방향별 개별 PNG 총 48장.
- `generation_prompts.json`: 내장 image_gen 제작 프롬프트.
- `export_report.json`: 원본 영역, 알파 제거, 크기 정규화와 발밑 정렬 기록.

## 방향 순서

미리보기 첫 줄: S 정면, SE 오른쪽 앞 대각선, E 오른쪽 옆면, NE 오른쪽 뒤 대각선.

미리보기 둘째 줄: N 뒷면, NW 왼쪽 뒤 대각선, W 왼쪽 옆면, SW 왼쪽 앞 대각선.

## 재생

모든 개별 프레임은 362×724이며 발밑 기준선은 이미지 위에서 711px 위치다.
6프레임 유지 시간은 순서대로 900, 350, 80, 110, 120, 700ms, 전체 2.26초다.
동일한 길이로 프레임을 재생하면 눈 감은 시간이 길어지므로 위 시간표를 사용한다.
정면과 측면은 호흡과 눈 깜빡임, 뒤쪽은 작은 어깨·옷 변화로 대기를 표현했다.

## 처리와 제한

그림은 내장 image_gen으로 생성했다. 허용받은 알파 후처리로 희미한 배경과 분리된 잔점을 제거하고, 투명 영역의 숨은 RGB도 비웠다.
방향별로 하나의 배율을 적용해 최대 캐릭터 높이 699px에 맞췄다. 각 프레임을 따로 확대·축소하지 않았으며, 발밑을 기준으로 전체 이미지를 정렬했다.
생성 프레임의 윤곽·옷 주름·얼굴에는 미세한 차이가 남아 있다. 모든 프레임을 수작업으로 일치시킨 최종 원화는 아니다.
Unity AnimationClip, Animator, 씬 연결은 이 이미지 제작 작업에 포함하지 않았다.
