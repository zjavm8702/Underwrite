# VillagePartsPilot v3 — 불규칙 판석 바닥 시안

**시안. 대비·반복·알파·마스크 검수 완료, 판석 크기·세로 비율은 미달이 남아 전체 완료가 아니다.** PNG까지, Assets와 Unity는 쓰지 않았다.

## 변경과 보존

- ground.png와 walkable.png만 새로 제작했다. 사물12장과 layout.json은 v2 바이트 그대로 복사, SHA-256 모두 일치. 사물별 해상도·foot·pivot_in_png·배치 좌표는 layout.json 그대로다. 바닥과 마스크는1920×1080 RGBA8이다.
- 생성은 내장 image_gen. 원화의 크기 교정이 잘 반영되지 않아9회 생성/편집했다. 축소 원화를 가운데 놓은 가이드를 입력하고 바깥을 새로 그리는 outpaint 후 색조만 수정한 sources/ground_color_final.png를 선택했다. 최종 전체 원본1672×941을1920×1080으로1회 보간한 결과이며 네이티브1920 세부가 아니다. 최종 패치 복사·타일링·반전은 없다.
- 왼쪽 위 빛의 오른쪽 아래 투영 그림자와 실제 사물별 불투명 최하단에 맞춘5px 접지 그림자는 v2 빌드 로직을 그대로 사용해 바닥에 구웠다. 사물 원본에는 넣지 않았다.
- 문 앞에서 광장으로 밝게 닳은 길, 가장자리 흙·풀을 유지했다. 최종 평균 RGB(180.480,152.102,122.945), v2(187.388,158.138,121.444)보다 약간 어둡다.

## 판석10개 실측 — 미달을 포함해 기록

## 여관 뒤편 마스크

- 기존 footprint 합집합에 여관 x695..1384, 위쪽y80부터 기존 footprint 후면 경계까지의 보수적 다각형을 추가했다. 정확한7개 꼭짓점은 verification.json의 walkable.rear.polygon. 지붕의 전체 수평 범위를 포함한다. NPC 머리가 지붕 위로 나오는 뒤편 영역을 막는다.
- 새로 막은325,454px, 총359,245px. 기존 검정이 흰색으로 바뀐 픽셀0. 예상 합집합 불일치0, RGBA불투명 값0/255만 존재.
- 좌우 통로 x675/1405, y350/550 네 지점 모두 흰색이며 여관 바깥 좌우 영역은 기존마스크 그대로다. 전체 지붕 실루엣보다 다소 넓게 막은 보수적 영역이다.
- walkable_overlay.png에서 빨강=새 차단, 청회색=기존 차단. layout.json의 footprint를 수정하지 않고 마스크만 추가했으므로 연결 담당자는 footprint-only로 재생성해 덮어쓰지 않는다.
