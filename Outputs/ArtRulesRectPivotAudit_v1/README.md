# 아트 작업규칙 Rect·피봇 조사 및 정정

2026-10-16. 완료: 문서 수정만 수행했다. 이미지 생성·수정, 메타 변경, Unity API 실행은 없다.

## 변경

- 아트 작업규칙 §7의 기존 PNG만 교체·메타 유지 지시는 보존했다. 기존 Rect 안 실루엣 포함 조건, 교체 전후 알파32 이상 Rect 초과 전수 검사 및 최종 보고, Rect 재계산 사전 승인·연결 보존·백업·피봇 처리·재검증 절차와 Batch Trim 탐색 범위를 추가했다.
- §10 과거 제작 기록은 바이트상 동일하게 보존하고, 인간 여성 Idle 현재 기준을 후속 기록으로 추가했다. 기존 (256,13)은 당시 권장값이며 현재 실제 피봇은 48장 모두 개별 Rect 중심 Custom(9)+(0.5,0.5)이다. 사용자 수용 X 편차는 5.5~13.5px다.
- 그 외 절과 주인공 발밑 좌표 표기는 변경하지 않았다.

## 조사 결과

- 인간 여성 Idle: S/SE/E/NE/N/NW/W/SW 방향당6장, 합계48장, 모두512×724. 현재 Rect 밖 알파32 이상0픽셀, 숨은 RGB0, 캔버스 접촉0. 연결 성분·실제 재생은 이번 문서 작업에서 검사하지 않았다. 과거 머리카락 미리보기 기록은 균등200ms×6=1.2초 반복이며 Unity 재생 검증값은 아니다.
- PNG의 IHDR·IDAT를 원본 바이트에서 읽고 zlib 해제 및 PNG 필터 복원 후 검사했다. PNG 좌표 y를 Unity 아래쪽 좌표 height-1-y로 변환하고, Rect의 x/y 이상·x+width/y+height 미만 범위와 대조했다.
- 백업 Rect와 대조한 방향별 알파32 이상 초과 수는 사용자 전달 수치와 모두 일치하며 합계24,460픽셀이다. 사용자 전달 알파255 합계14,445픽셀은 재현되지 않았고 현재 원본에서는421픽셀이다. 서로 다른 측정값을 합치거나 전달 수치를 확정값으로 쓰지 않았다. 원인 미해결.
- 백업164353은42장,151956은E6장이다. 현재 48장 모두 Custom(9)+(0.5,0.5).164353 백업42장은 Center(0),151956의E6장은 Custom(9)+(0.5,0.5)로 모두 의미상 Rect 중심이다.
- 현재 Batch Trim 기본값은 이미지 전체다. 기존 영역 안에서만 모드는 Rect 밖을 탐색할 수 없다. 도구 코드는 변경하지 않았다.
- 주인공 실제 개별 Sprite alignment는 Idle48/Walking64/Cheer64 모두 Center(0)다. 저장 pivot 숫자가0이어도 Center 열거값이 적용되어 유효 피봇은 Rect 중심이다. 걷기의 캔버스 절대 피봇은(320,362), Idle은 X171~189/Y361~362.5, Cheer는X228~275.5/Y325~382.5로 문서 발밑 좌표와 불일치한다. 요청에 따라 보고만 하며 수정하지 않았다. 방향별 상세는 verification.json.

## 보존 검증

- 캐릭터 폴더 메타263개 및 PNG224개 SHA-256 전후 동일. 변경0개.
- 아트 작업규칙의 §7·§10 외 모든 절 동일, §10 기존 기록 전체 동일. 원문 및 작업 전 해시는 before.json에 보관했다.
- generation_prompts.json·프레임·미리보기는 문서 작업이므로 생성하지 않았다.
