## 구도와 화풍

기존 지하실의 비도트 2D 선, 무광 참나무·석재·양피지 색의 뿌리를 유지했다. 여관은 따뜻한 호박색 창빛과 술잔·술통, 기록실은 서늘한 회청색과 정돈된 장부·두루마리·서랍, 광장은 낮의 하늘·건물·시장 천막·무문자 게시판으로 구분했다. 전체 평균 밝기는 지하실 < 여관 < 기록실 < 광장 순서다. 왼쪽 인물 자리에는 밝은 창이나 기둥을 두지 않았다. 바닥 선과 벽의 넓은 명암은 남아 있으나 아래쪽은 어두운 값으로 묶었다. 사람·동물·글자·숫자·간판 문구 없음.

## 밝기 측정 표

좌상단 원점, 구간 끝은 제외. sRGB luma Y′ = 0.2126R + 0.7152G + 0.0722B, 0~255. 모집단 표준편차. 선형 상대휘도와 구분한다. 아래 1/3은 x0..1920,y720..1080, 인물 자리는 요청의 x300..900과 동일하게 **y0..1080 전체 높이**를 사용했다.

| 배경 | 아래 평균 | 아래 표준편차 | 인물 평균 | 인물 표준편차 | 전체 평균 |
|---|---:|---:|---:|---:|---:|
| 기존 지하실 | 20.0085 | 4.2280 | 18.0842 | 3.6638 | 21.8183 |
| 여관 | 24.5853 | 4.5137 | 28.3907 | 9.7107 | 33.0343 |
| 길드 기록실 | 36.6660 | 5.9362 | 40.0938 | 7.9308 | 44.1820 |
| 시장 게시판 광장 | 30.7063 | 5.1884 | 37.8151 | 10.6281 | 58.5159 |

종이색 Y′=231.8224. 아래 영역 최대 밝기: 여관 61.26 / 기록실 75.42 / 광장 61.22 / 지하실 46.51. 세 신규 배경의 모든 아래 픽셀이 종이색보다 Y′ 156 이상 어둡다. 밝기 분산의 수치 합격 임계값은 사용자 지시에 없으므로 임의의 공식 기준을 만들지 않았으며, 위 측정값과 합성 이미지의 시각 점검을 근거로 가독성 확보를 판단했다.

## 알파·보존

- 신규 PNG 각각 2,073,600픽셀 모두 알파255, 분리 성분0개(연결 성분1개), 숨은 RGB0픽셀.
- 전체 화면 배경이므로 사방 캔버스 접촉은 의도된 full-bleed다. 캐릭터 실루엣 잘림 기준은 해당 없음. 의도하지 않은 프레임·투명 여백 없음.
- Assets/**/*.meta SHA-256 **454개 유지 / 변경0 / 추가0 / 삭제0**. before.json에 작업 전 전체 해시, verification.json에 작업 후 전체 해시와 비교 결과.
- 기존 지하실 PNG 및 프로젝트 문서 변경 없음. 기존 산출물 덮어쓰기 없음.

## 생성·기록

기본 제공 image_gen 사용, CLI/API fallback 미사용. 전체 프롬프트와 참조는 generation_prompts.json, 생성 원본은 source/*_generated.png. 원본 1672×941을 전체 캔버스 bilinear 보간으로 1920×1080에 맞추고 알파255 RGBA8로 저장했다. 크롭·구조 변형·추가 채색 없음. 검수 도형 합성과 수치 측정은 Node pngjs로 수행했다. 생성 원본은 보존했다.

원문 확인: Documents/Codex/Underwrite_아트_작업규칙.md, Documents/Codex/Underwrite_8방향_애니메이션_자동생성툴.md, Documents/Shared/Underwrite_기획서_v0.5.md, AGENTS.md, Documents/README.md, Outputs/UnderworldScene_v1/README.md. 기존 지하실 underworld_room.png를 직접 시각 확인하고 생성 참조로 사용했다.
