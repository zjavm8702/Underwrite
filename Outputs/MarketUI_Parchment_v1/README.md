## 납품 PNG와 9-slice

|---|---|---|---|

| market_selection.png | 256×128 | **24 / 24 / 24 / 24** | 12px |

피봇은 PNG에 저장되지 않으며 Unity 미설정. UI용 권장 Center(0.5,0.5). PPU 미설정. Border는 원본 픽셀 기준이다. 테두리/모서리를 고정하고 가운데 및 변 중앙만 Stretch한다. 패널은 최소 96px 초과, 선택 바탕은 48px 초과의 폭·높이에서 사용한다. 원본 해상도 유지, 비도트 Bilinear, Mipmap 끄기를 적용 단계에서 검토한다. 화면 바탕은 단일 이미지이며 타일 반복 이음새는 보장하지 않는다.

## 표현과 검사

옅은 중성 아이보리 장부 종이와 무광 짙은 나무 탁자. 종이 중앙은 거의 평면이고 마모는 가장자리에 집중했다. 납품 PNG에는 글자·숫자·기호·그림자·글로우가 없다. RGBA, 패널/선택 바탕 바깥 둥근 모서리만 투명. 전체 화면 바탕은 불투명이다.

- 알파32 이상 연결 성분: 각 1개, 분리 잡성분 0개. 숨은 RGB 0픽셀.
- 배경용 full-bleed 이미지이므로 상하좌우 캔버스 접촉은 의도된 구조다. 캐릭터의 캔버스 접촉 금지 규칙을 적용하지 않았다.
- 중앙 상대 휘도 표준편차: 패널 0.00715, 선택 0.00740. 화면 바탕 평균 휘도 0.02468, 패널 0.76132, 선택 0.86488.
- 중앙 전 픽셀 중 최소 글자 대비(패널 / 선택): 잉크 #2A2118 **11.80 / 13.09**, 상승 #C53643 **3.94 / 4.37**, 하락 #245EC7 **4.48 / 4.97**, 비공개 #6741B0 **5.30 / 5.88**.
- 상승색은 현재 20px 굵은 숫자에서 검토했다. 16px 일반 크기까지 모든 강조색이 4.5:1 이상이라고 주장하지 않는다.
- 9-slice 미리보기에서 패널 500×120, 840×120, 300×660, 1040×260, 420×380, 600×120 및 선택 바탕 552×120을 검사했다. 모서리 고정, 이음새·장식 단절 없음.
- 밝은/검은 배경 테두리 검사는 alpha_edges_preview.png. 모서리 잘림·잔점 없이 확인했다.
- 기존 Assets .meta **378개 해시 유지, 변경 0개**. 작업 도중 다른 실행 주체가 만든 것으로 보이는 Assets/Temp/ui_13.png.meta, ui_14.png.meta 2개 추가 감지. 본 작업은 Outputs에만 썼고 이 파일들은 수정하지 않았다.
- 정적 UI 이미지 3종이며 방향·프레임·반복/일회·재생 시간은 해당 없음. Unity 실행 검증은 범위 밖이다.

## 가독성 합성 이미지

## 생성·보관

기본 제공 image_gen 사용, CLI/API fallback 미사용. 생성 프롬프트 전문은 generation_prompts.json. 원본 source/ 3종과 생성 시각, 원본 경로는 staging.json 및 before.json, verification.json 참고. 원본은 각각 1254×1254, 1672×941, 1774×887이어서 요청 크기로 premultiplied-alpha bilinear 변환했다. 알파32 미만 제거, 숨은 RGB 정리, 반경16/12 둥근 모서리 알파만 정규화했다. 원화 질감을 코드로 새로 만들거나 바꾸지 않았다.

기존 파일 덮어쓰기 없음. 프로젝트 규칙 문서 갱신 없음. Unity 연결/Border 입력은 Claude Code의 다음 단계다. 승인 전 시안 표시를 유지한다.
