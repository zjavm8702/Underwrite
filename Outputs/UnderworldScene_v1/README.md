## 생성·후처리

기본 제공 image_gen 사용. CLI/API fallback 미사용. 전체 프롬프트는 generation_prompts.json. source/room_generated.png와source/room_dim_generated.png는 생성 원본1672×941이며 같은 기준으로 전체 캔버스를1920×1080으로 bilinear 변환했다.

생성된 조명 편집판은 육안으로 같은 방이지만 gradient 정합 검사에서 최적offset(0,-1), NCC0.79755로 미세한 재해석을 발견했다. 구조선 불일치 조건을 충족하기 위해 최종 dim에는 편집판의 구조 픽셀을 쓰지 않고, 편집판에서24×14 밝기 배율 격자를 추출해0.30..0.82로 제한하고 부드럽게 보간하여 기본판의 동일 픽셀에 적용했다. 새 그림이나 구조를 코드로 만들지 않았고, 생성된 조명 차이를 구조 보존 방식으로 정합 보정했다. source/illumination_field.json에 실제 배율을 보관했다. 따라서 dim에서 등불 모양과 불꽃 윤곽은 그대로이며 빛의 세기만 감소한다.
