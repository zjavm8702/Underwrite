# 정보 출처 표식 v1 — 승인 전 시안

2026-10-16. 정적 UI 표식 5종 제작·검증 완료. 사용자 승인 전 시안이다. 방향·프레임·애니메이션 재생시간은 해당 없음. PNG까지, Outputs에만 납품했다. Assets와 Unity 연결은 변경하지 않았다.

## 파일과 순서

1. mark_tavern.png — 여관 소문: 오른쪽 손잡이가 드러나는 술잔.
2. mark_guild.png — 길드 기록: 둥근 손잡이와 넓은 받침의 공식 도장.
3. mark_letter.png — 사적 편지: 가로로 긴 편지와 밀랍, 투명 V자 접힘.
4. mark_board.png — 시장 게시판: 위쪽 돌출 가로대와 두 발이 있는 세로 게시판.
5. mark_broker.png — 중개인 유출: 비대칭 뾰족 두건과 가려진 얼굴, 어깨.

모두 96×96 RGBA, 가시 RGB #FFFFFF만 사용. 완전 투명 RGB=0. PNG에는 피봇·PPU가 없으며 UI 중앙 (48,48), 정규화 (0.5,0.5)를 권장한다. 임포트 설정은 생성하지 않았다.

## 비교 검수

InfoSourceMarks_preview.png는 잉크(#2A2118)·종이(#F2E7D2) 두 바탕을 합친 비교판이다. 열은 위 순서, 행은 96 / 20 / 24 / 28px다. 축소 아이콘은 실제 픽셀 크기로 배치했다. preview_ink.png와 preview_paper.png로도 개별 확인 가능. 종이판에는 잉크색 틴트, 잉크판에는 흰색을 사용했다. 납품 원본은 흰색 그대로다. preview.html은 이름과 실제 크기를 함께 확인하는 보조 자료이고, 정확한 두 색은 PNG 비교판 기준이다.

20px에서 술잔의 옆 손잡이, 도장의 둥근 손잡이와 넓은 바닥, 편지의 낮은 가로 윤곽, 게시판의 높은 세로 윤곽, 중개인의 뾰족 두건과 어깨가 서로 구분된다. 24·28px에서도 확인했다. 표식만으로 정보 신뢰도를 자동 판정하는 기능은 추가하지 않았다.

## 제작과 재현

기본 image_gen 도구로 각 표식을 개별 생성했다. sources/에 생성 원본 5장을 보존한다. generation_prompts.json에 프롬프트 전문을 저장했다. 참조는 Outputs/MarketUI_Icons_v1/MarketUI_Icons_preview.png이며 넓은 단색 실루엣·미세한 손맛·장식 없는 마감을 따랐다. 새 형상은 코드로 그리지 않았다.

생성 알파를 유지하며 작은 잡성분 제거, 거의 불투명한 내부 알파 정리, 균등 비율 축소 및 면적 평균 샘플링만 수행했다. 최대 변 76px, 가중 면적 목표 2000px²로 조절한 뒤 최종 알파32 미만 제거와 흰색/숨은 RGB 정리를 했다. 수동 도형 추가·미러링·왜곡은 없다. build.mjs와 processing.mjs에 재현 코드를 남겼다.

## 보존·범위

작업 전후 Assets/**/*.meta 416개 모두 SHA256 유지. 기존 메타 변경·삭제 0개. 최종 재검사 시 신규 메타 2개가 외부 작업 중 감지되었다. 본 작업은 Assets를 쓰지 않았다. 신규 경로: Assets/Temp/ui_fav.png.meta, Assets/Temp.meta. before.json에 작업 전 해시, verification.json에 검사 수치, staging.json에 최종 경로와 PNG 해시, source_paths.json에 생성 원본 경로를 기록한다. 기존 아트 문서는 변경하지 않았다.
