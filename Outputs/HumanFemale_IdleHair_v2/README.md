# 인간 여성 용사 Idle 머리카락 수정

8방향 각각 6프레임, 총48장. 포니테일 묶음의 뿌리를 기준으로 하단 머리와 리본 끝의 움직임을 다시 그렸다. 기존 파일명·512×724 캔버스·프레임 수를 유지하여 `Assets/Images/Characters/Heroes/HumanFemale/Idle/{방향}`의 PNG만 교체한다. 기존 메타·애니메이션·컨트롤러는 수정하지 않는다.

기본 제공 image_gen으로 그림을 편집했다. 전체 프롬프트·참조·선택 원본 경로는 generation_prompts.json에 있다. 코드 후처리는 알파32 미만 및 분리 잡점 제거, 완성 인물의 동일 비율 리샘플링, 발 기준 정렬, 분할·미리보기 출력에만 사용했다. 인물이나 머리카락을 코드로 휘게 만든 결과가 아니다.

미리보기는 프레임당200ms, 한 주기1.2초로 반복한다. 이전의 눈 깜빡임용 긴 정지 시간(900/350/80/110/120/700ms)을 그대로 사용하면 머리카락이 멈췄다가 급히 움직일 수 있다. Unity 클립을 이미 연결했다면 이미지 교체는 반영되지만 재생 시간은 기존 클립을 따른다. 클립 설정은 이번 PNG 교체 작업에서 변경하지 않았다.

Before에는 교체 직전48장, before.json에는 기존 PNG와 캐릭터 메타의 해시를 보관한다. verification.json은 실제 교체 후 검증 결과다. 원본 편집 과정에서 세부 의상 윤곽·장식·머릿결에 미세한 차이가 남아 있으며, 현재는 6프레임으로 교체 가능한 작은 움직임의 시안이다. 8~12프레임 확장판은 별도로 제작하지 않았다.
