# 주인공 걷기·대박 모션 v1

제작일: 2026-10-15. 비도트 2D 스프라이트 애니메이션 시안.

## 구성

- 걷기: S/SE/E/NE/N/NW/W/SW **8방향 × 8프레임 = 64장**.
- 대박: **정면 1방향 × 8프레임 = 8장**. 놀람·힘 모으기·주먹을 든 점프·착지·정리.
- `Walk_8directions_preview.png`: 8방향 동시 반복 APNG. 순서는 위 S/SE/E/NE, 아래 N/NW/W/SW.
- `Walk_*/Walk_*_preview.png`: 방향별 걷기 반복 APNG.
- `Jackpot_S/Jackpot_S_preview.png`: 대박 APNG 미리보기. 게임에서는 일회 재생으로 사용한다.
- 각 동작 폴더: 4×2 스프라이트 시트와 개별 투명 PNG.
- 프로젝트 PNG: `Assets/Images/Characters/Protagonist/Motion_v1`.

## 크기와 재생

| 동작 | 프레임 크기 | 피봇: 이미지 아래쪽 기준 | 시간 |
|---|---|---|---|
| 걷기 | 640×724 | (320, 13) | 프레임당 100ms, 1바퀴 0.8초 |
| 대박 | 512×960 | (256, 13) | 180/120/100/120/160/120/360/220ms, 총 1.38초 |

걷기의 큰 보폭 때문에 Idle보다 가로 캔버스를 넓혔다. 대박은 머리 위 주먹과 점프 여백을 포함한다. 각 프레임을 자동 Trim한 뒤 Center 피봇을 쓰지 않고 공통 캔버스와 기준점을 유지한다.

## 제작·후처리

원화는 내장 image_gen을 사용했다. 전체 프롬프트는 `generation_prompts.json`에 기록했다. 무광 의상, 적은 잔주름, 고정된 색·명암, 동일한 성인 비율을 지시했다.

사용자가 허용한 알파 정리를 적용했다. 알파 32 미만과 분리된 배경 성분을 제거하고, 완전 투명 픽셀의 숨은 RGB도 비웠다. 실제 인물의 연결 성분을 기준으로 추출해 불규칙한 원본 칸 간격으로 인한 잘림을 피했다.

방향별 하나의 배율로 전체 프레임을 처리했다. 걷기는 몸통 중심과 접지선을 기준으로 등록했다. 대박은 첫 중립 자세의 실제 키를 배율 기준으로 쓰고, 웅크리기를 작게 확대하거나 점프한 발을 다시 접지선에 붙이지 않았다. 점프 프레임의 전체 위치를 위로 100px 배치해 도약을 표현했다. 관절이나 옷을 코드로 변형한 결과가 아니다.

## 현재 상태

동작과 감정, 방향별 실루엣을 검토하는 시안이다. 생성 프레임에 의상 선·명암 차이와 보행 간격의 불균일이 남아 있다. 자글거림이 완전히 해결된 최종 애니메이션으로 표시하지 않는다. 큰 동작이 포함된 만큼 실제 게임 크기에서 보행 리듬과 착지 타이밍을 확인해야 한다.

기존 Idle, Sprite Library, Animator의 동작 연결은 교체하지 않았다. 새 프레임의 임포트 설정은 `unity_import_report.txt`, 알파·잘림 검사는 `validation.json`에 기록한다.
