## 추가 조사처

- [Stylized Textures 목록](https://stylizedtextures.com/browse): 검색 결과에서 Stone Floor011 등과 4K 설명을 발견했다. 원본 사이트의 License Information 링크가 CC0로 연결되는 것은 확인했다. 다만 동적 목록에서 개별 파일 목록·해상도·무료 다운로드 범위를 확인하지 못했다. 조건 확인이 끝난 후보로 격상하지 않았다.
- ambientCG / Poly Haven 검색: 무료 CC0 PBR 석재 자료가 검색되었으나, 이번에 원본 페이지·파일 범위까지 확인한 Poly Haven 후보는 위 표에 한정한다. 검색 결과만으로 손그림 질감이라고 판정하지 않았다.
- OpenGameArt의 CC0 손그림 모음도 검색했지만 모음의 라이선스를 개별 파일의 증거로 대신하지 않았다.

UI 에셋이 아니므로 9-slice 폭·최소 표시 크기는 해당 없음. 외부 에셋이 최종 PNG에 들어가지 않으므로 Claude 소유의 출처 문서는 수정하지 않았다. 원본 미수급을 “고해상도 무료 손그림 자료가 세상에 없다”는 근거로 일반화하지 않는다.
