## 결론과 증거의 범위

깔끔함은 정보의 절대량보다 **지금 비교할 값의 정렬, 읽는 순서, 보조 정보의 지연 공개**에서 나온다. 토스 모바일의 집중 방식과 PC의 동시 비교 방식을 함께 취한다. 현재 토스 PC에는 다열 표와 여러 영역이 있다. 따라서 '토스는 모든 화면에 정보가 적다'를 보편 법칙으로 삼지 않는다. 최신 앱 전체를 로그인해 실측한 조사는 아니며, 공식 공개 제품 화면·설명·TDS·제작사 자료에 한정한다. 정확한 px와 시간은 아래에서 명시한 Underwrite 설계값이며 토스의 내부 수치를 추정해 사실처럼 제시하지 않는다. 사용자 선호 평가는 요청의 디자인 기준이지 시장 전체 선호도 조사 결과가 아니다.

## 상승·하락과 접근성

한국어 UI 기본은 상승 빨강+▲와+, 하락 파랑+▼와−. 0은 회색 '0.0% · 보합'. 이는 사용자 지정 규칙이다. 미국/유럽 시장에서는 녹색 상승·빨강 하락 조합을 흔히 보며 Robinhood 공식 예제도 이를 사용한다. 지역을 절대 규칙으로 삼지 않는다. 특히 중국권은 상승 빨강·하락 녹색이 일반적이어서 요청의 '한국·중국=빨강/파랑' 설명은 그대로 일반화하지 않는다. 해외 색 관례는 [Webull 공식 색 설정 설명](https://www.webullapp.com.sg/learn/vVQ8Hz/u3aRPl)처럼 선택 가능한 경우도 있다. [홍콩거래소 공식 FAQ](https://www.hkex.com.hk/Global/Exchange/FAQ/Getting-Started/Overview-of-the-listed-market?sc_lang=en)는 홍콩의 상승 녹색·하락 빨강과 중국 본토의 상승 빨강·하락 녹색을 구분한다. 게임 적용은 한국 관례로 고정한다.

색 외에 부호·방향 화살표·상태 문구를 모두 병기한다. 보라색은 수익 방향이 아니라 정보 공개 범위만 의미한다. 글씨 대비는2단계 verification.json에 계산값을 남긴다. 포커스는2px 진한 외곽선, 클릭영역은 최소44px, 색만으로 선택 상태를 전하지 않는다.

## 코드·기획 검토로 달라진 설계

| 발견 | 설계에 반영한 결과 |
|---|---|
| 가격 이력은 float 배열, OHLC/거래량 시계열 없음 | 선 차트만. 유동성을 거래량으로 위장하지 않음 |
| SessionChangeRatio는 장 시작가 기준 | '장 시작 대비'를 등락 옆에 명시. 전일 대비 문구 금지 |
| 480분/5분=96틱, 초기 가격도 이력에 포함 | 0~96의97개 관측점 가능. 미래 영역은 빈 공간, 미래 경로 생성 금지 |
| 시계는 실제 시각이 아닌 경과 분 | '장중 경과02:50' 표시. 임의09:00 개장 시각을 정하지 않음 |
| 시장가 fill=Price+OrderImpact/2 | 현재가×수량을 확정 합계로 쓰지 않음. 예상 체결가·예상 합계·체결 시 변동 안내 |
| IsPaused는 AcceptsOrders 조건에 없음 | 개장 중 정지 상태에서도 주문 허용. 기획의 미확정 부분은 현 코드를 따름 |
| InfoEntry는 출처와 공개 여부만 보유 | 신뢰도 퍼센트 금지. '기록 근거/직접 서신/재확인 필요'는 출처별 보조 문구라는 설계 제안 |
| TruthOnly는 플레이어에게 비공개 | 실제 내재가치·시장 기대 수치·미래 사건·정답 표시 금지 |
| 휴장 중 시계·사건은 진행, 가격만 고정 | 휴장 배너+마지막 거래가+주문 비활성, 정보 기록과 시간 조절은 유지 |
| 초기 종목은 셀라/브란/블랙무어 단, 시작 현금500 | 시안 이름은 이3개. 용사5명을 투자자로 사용하지 않음 |

## 수집·권리·재현

타사 스크린샷을 납품 PNG에 포함하거나 복사하지 않았다. 공식 화면 이미지 URL을 참고용 링크로만 남긴다: [미래에셋 현재가 개편 공개 이미지](https://digital.securities.miraeasset.com/img/maps/tab2_1_v2.png). 기타 참고화면은 위 제품/가이드 원문 URL로 접근한다. 로그인 계좌나 개인 데이터는 수집하지 않았다. 조사와 시안의 독자적인 토큰·배치는 구분한다. 토스 전용 서체/로고/아이콘은 가져오지 않는다.

## 조사 한계와 변경을 유발한 발견

1. 토스 PC도 밀도가 높다. 완성형에3열 구조를 허용하되 한 영역에 한 목적을 유지하는 방향으로 변경했다.
2. 미래에셋은2026-10-01부터 M-STOCK→MAPS 안내가 공개돼 있다. 구 명칭만을 최신 앱처럼 보고하지 않았다.
3. 모션 실측 영상과 로그인 앱 전 화면 비교는 미완료다. 모션 수치는 토스 관찰값이 아닌 게임 제안이다.
4. 출처 신뢰도는 코드에 수치가 없다. 출처별 기본 문구는 구현 담당자가 검토할 설계 제안이며 확률/실제 진위를 보장하지 않는다.

삼성 모바일 보완: [삼성증권 공식 블로그의 mPOP 가이드](https://blog.onestopsamsungpop.co.kr/mobile-stock-investment-guide)는 홈에 보유 종목 시황·리포트·매매 일지를 함께 제공한다고 설명한다. POP HTS의 여러 전문 화면과 달리 개인이 필요한 정보의 홈 요약을 채택하는 흐름으로 해석했다. 실제 로그인 화면의 픽셀 밀도 수치는 미측정이다.
