## 미해결·주의

- 사용자 승인 전 시안이며, 생성 원본 확대에 따른 부드러움이 있다.
- 카메라 행렬이 없는 회화다. 상판 세 곳의 측정 통과가 장면 전체의 기하학적 일관성을 증명하지는 않는다.
- 충돌 마스크는 화면 투영 영역을 보수적으로 막는다. 건물 뒤 통행이나 발밑 전용 충돌이 필요하면 별도 설계해야 한다.
- 이번 명시 요청에 따라 일반 Assets 납품 규칙 대신Outputs에만 납품했다. 캐릭터 애니메이션 자동 연결 규칙은 정적 배경에 해당하지 않는다.
