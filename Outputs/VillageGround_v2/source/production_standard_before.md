작성: 2026-10-16. 첫 적용: Outputs/VillageGround_v1. **사용자 시각 승인 전 시안의 제작·검수 기준**이며 승인된 최종 건축 디자인으로 간주하지 않는다.

## 범위와 기준 화면

영지는 도트 타일셋 대신 연속된 비도트 2D 그림 한 장으로 제작한다. 지도는 3840×2160, 카메라 검수 창은 1920×1080이다. PNG는 불투명 RGBA8이다. 가로와 세로가 각각 카메라의 두 배이며 면적은 네 배다. 캐릭터와 경계·충돌 구현은 별도다.

## 시점 — 2026-10-17 v2 요청으로 갱신

**현재 기준은 실제 원형 수평 상판의 화면상 세로÷가로 0.45~0.55다.** 원형 탁자, 통 뚜껑, 원형 우물 테두리 등 서로 다른 둥근 물건 셋을 측정한다. 중심 목표 0.50은 직교 투영을 가정하면 약30도 하향에 해당하지만, 회화의 실제 카메라 각도를 보장하는 값은 아니다. 0.45 아래로 낮추지 않는다. v1의 높은 조감·약55도 프롬프트 목표는 폐기하며, v1 실측 예시0.66(약41도)은 현재 허용 범위 밖이다.

각 건물의 **정면 벽 높이 : 보이는 지붕 깊이 = 2:1 이상**을 함께 확인한다. 벽은 주 처마 아래부터 접지까지, 지붕 깊이는 같은 지붕 면의 용마루부터 주 처마까지 화면의 수직 거리로 잰다. 굴뚝·장식 첨탑은 지붕 깊이에서 제외하고, 박공지붕 삼각면을 정면 벽에 더해 통과시키지 않는다. 게시판도 처마 아래 전면 구조 높이와 지붕 깊이를 비교한다.

수평선·하늘 없이 바닥이 충분히 남는 낮은 사선 시점이다. 화면 아래가 S이며 세 입구는 아래를 향한다. 영지 확장과 다른 장소에도 같은 상판 비율, 지면 축, 왼쪽 위 낮 빛을 적용한다. 캐릭터와의 접지는 지정 protagonist.png를135px 높이로 축소해 세 입구 앞에 놓고1920×1080 원배율 크롭으로 확인한다.

## 사람과 시설의 크기

사람의 표시 높이는 **1920×1080 카메라에서 135px = 화면 높이 1/8**로 잡는다. 월드 지도 픽셀과 카메라 픽셀이 1:1인 검수에서는 3840×2160 지도에도 동일하게 135px다. 전체 지도 높이의 1/8인 270px로 혼동하지 않는다. 검수는 지정된 Assets/UI/Images/Heroes/protagonist.png를 종횡비 유지하여 45×135로 축소했다. 원본 초상화는 시점이 다른 크기 비교용이며 필드 걷기 검증을 대신하지 않는다.

문 높이 약170px, 탁자 약65px는 생성 목표다. 생성본의 모든 물체가 그 수치와 정확히 일치하는 것은 아니다. 첫 시안에서 시설이 커 보여 image_gen으로 시설과 소품 축소 수정을 수행했고 세 장소 합성으로 재검토했다. 건물 위치에 따른 원근 축소는 최소화한다.

바닥은 타일셋이 아닌 불규칙 판석 그림이다. 요청의 사람 키 두 장 남짓은 넓은 판석의 시각적 기준이며 정규 격자가 아니다. 현재 시안은 세로 이음선 기준 약3~4단이 보여 두 장 기준과 차이가 남았다. 이 차이를 새 표준으로 승인한 것으로 취급하지 않는다. 확장 시 사람135px를 고정한 합성으로 판석 크기를 다시 판단한다.

## 바닥과 장애물 구분

밝은 회베이지 판석은 통행 공간, 더 어두운 흙·풀과 연석은 건물·소품이 차지한 공간이다. 입구 앞은 밝은 포장으로 열어 둔다. 바닥 무늬는 얌전하게 유지한다. v2부터 중앙 우물/분수1개, 등주3~4개, 상자·통·천막·화단·수레·장작을 흩어 배치하고 색이 조금 다른 다져진 길로 시설을 잇는다. 세 입구와 중앙 장애물 양옆에는 이어지는 통행 공간을 둔다. 맵 사방은 담·울타리·식재로 닫고 허공이나 하늘이 드러나지 않게 한다.

v2 납품명은 **village_walkable.png**이며 흰색255=통행 / 검은색0=장애물, 알파255인3840×2160 이진 충돌 입력 마스크다. 건물·담·우물·좌판·등주·상자·통·수레·화단은 막는다. 통행 영역은4방향 flood fill로 세 입구와 중앙 우물 양옆이 연결되도록 검수하고 고립된 통행 조각은 제외한다. v1의 검수용 walkable_mask.png는 흰색 통행 / 검은색 장애물의 보수적 수동 표시다. v2도 지붕·수관 투영 영역까지 보수적으로 제외하므로, 물체 뒤로 숨는 이동을 허용하는 발밑 전용 충돌과는 다르다. 좌표는 원본PNG 좌상단 기준이고 Unity 텍스처 좌표가 아래 원점이면 Y를 반전한다. 캐릭터 반경에 따른 통행 영역 축소는 런타임에서 별도 적용한다. 오버레이는 초록 통행 / 붉은색 제외다. 4방향 flood fill로 연결 여부를 검사한다. VillageGround_v1에서 통행 4,583,476px(55.2599%), 연결 성분1개, 세 접근 지점 모두 같은 성분이다. 실제 Collider/NavMesh는 별도 설계가 필요하다.

## 화풍·검수·보존

GatherPlaces_v1 세 장의 따뜻한 선, 무광 목재·석재·기와 팔레트를 따른다. 실외 낮 장면은 실내 대화 배경의 어두운 전경 처리를 복제하지 않는다. 사람·동물·글자·숫자·간판 문구 없이 사물로 장소를 구별한다.

전체 지도에 세 캐릭터 합성, 세 곳의 1920×1080 카메라 원배율 크롭, 통행 오버레이, 기존 배경과 비교를 저장한다. 불투명 배경의 알파 연결 성분은1개이고 분리 성분은0개다. 사방 캔버스 접촉은 의도한 full-bleed이며 캐릭터 실루엣 잘림 규칙을 기계적으로 적용하지 않는다.

내장 생성 도구 원본은 이번에 1672×941로 나왔다. 3840×2160은 전체 이미지 bilinear 보간 확대이며 네이티브4K 세부를 새로 만든 것으로 보고하지 않는다. 원본과 전체 프롬프트, 해시, 검수 결과를 보존한다. Assets 쓰기가 없는 작업에서도 전체 메타의 추가·삭제·내용 변경을 별도로 비교하고 다른 작업의 변경을 원복하지 않는다.
