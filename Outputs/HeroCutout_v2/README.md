# HeroCutout v2 — 갇힌 배경 제거 시안

6장 PNG 납품 및 검수 완료, 사용자 시각 승인 전 시안. 원래 이름·해상도·배율·크롭·사방8px 여백 유지. 정지 일러스트이므로 방향 시퀀스, 재생 시간, PPU, Unity 피봇은 해당 없음. Assets 및 프로젝트 문서는 수정하지 않았다.

## 측정

흰색 후보 = alpha>=200, RGB 모두244 이상, 채도(max-min)<=10. 비율 분모는 alpha>=200 픽셀 수. 이는 배경 확정 검사가 아니라 흰 의상·피부 반사광도 잡는 진단이다.

학자 0.351%로 1% 미만 통과. 모든 기존 반투명 픽셀의 위치·RGBA 값이 정확히 동일(수정0개), 새 틈 가장자리에만 반투명 추가. 6장 모두 알파 8연결 성분1개, 본체 분리 잔점0개, 숨은RGB0개, 캔버스접촉0개, alpha1..31=0. 여검사의 배경 제거로 떨어진 불투명 잔점2픽셀 제거. PNG 재독출 검사 완료.

## 처리 판단과 한계

RGB250 이상·채도4 이하 후보 연결성분을 실제 측정했으나 학자 다리/팔 사이의 확실한 배경도 밝기 표준편차1.23~1.47이었다. 제안된 SD<1을 필수조건으로 사용하면 실패가 반복되어 채택하지 않았다. RGB244·채도10 후보를 전역 8연결 분석한 뒤 원화의 신체/의상 경계로 제거 성분을 골랐다(candidate_components.json). 바깥과의 연결 여부는 판정 조건이 아니다. 선택 성분에서 불투명·minRGB>230·채도24 이하 영역으로 확장하고 2px 안쪽 경계에 가까운 전경색을 사용해 역합성, alpha32 미만만 정리했다. 기존 반투명 픽셀은 완전히 고정했다.

학자 다리 전체/팔틈, 여검사 머리카락·팔·검 손잡이 틈, 엘프 손과 머리카락 사이, 워리어 도끼 자루 옆 다리틈, 주인공 팔꿈치 안쪽 틈을 제거했다.

주인공 오른팔 바깥 흰 띠는 셔츠 외곽선 안의 빛나는 면이라 보존했다(inspect_protagonist.png). 요정에서 검출된 흰 부분은 날개 무늬·소매·치마의 실제 작화로 판정했으며 요정 PNG는 v1과 동일한 픽셀이다. 요정의 확실한 갇힌 배경은 이번 확대검수에서 확인하지 못했으므로 단지 비율을 낮추기 위해 지우지 않았다. 요정 검출비율은1.106%로 남으며, 1% 조건은 요청대로 학자에만 적용했다. 분홍 표시는 배경 확정 표시가 아니다.

원본 RGB만으로 반투명 실제 알파를 유일하게 복원할 수 없다는 v1의 한계는 유지된다. v1 알파/RGB를 그대로 보존한 시안이다. 머리·손·신발, 검은색에 가까운 #141014 및 흰색·지하실 합성을 확인했다.

## 재현과 보존

새 작화·이미지 생성 없음. 사용자 요청의 결정적 알파 정리 작업이다. generation_prompts.json에 생성 미사용 기록. corrections.json은 실제 변경 픽셀과 v1 SHA256, rebuild.mjs는 그 패치를 v1에 적용하는 재현 실행 파일이다. png-tools.mjs는 v1의 PNG 입출력 도우미를 ESM으로 복사한 것으로 v1 원본은 수정하지 않았다. 실행: node Outputs/HeroCutout_v2/rebuild.mjs (프로젝트 루트 기준).

v1 전체 파일 해시 동일. 기존 Assets 메타457개 해시 유지, 변경/삭제0개. 작업 중 외부에서 신규 메타4개가 관찰되었으며 after.json/verification.json에 목록을 기록했다. 본 작업은 Assets에 쓰지 않았다. Unity 연결은 요청 범위 아님. 프로젝트 아트 문서 수정 없음. 상시 지시서의 PNG범위를 적용했으며 상위 문서의 연결 완료 규칙은 애니메이션 제작에 관한 것이므로 이번 정지 일러스트 요청과 충돌하지 않는다.
