# Underwrite 주인공 애니메이션 비교 시제품 v1

2026-10-15 / Unity 6000.5.10f1 / 비도트 2D 일러스트

## 바로 보기

- `index.html`: 여섯 동작의 PNG 재생, 일시정지, 프레임 이동, 속도·배경 변경.
- `Idle.png`, `Walk.png`, `Anxious.png`, `Surprised.png`, `Downcast.png`, `Relieved.png`: 투명 배경 애니메이션 PNG(APNG). APNG 지원 브라우저에서 움직인다.
- `frames/`: 게임에서 사용할 일반 PNG 프레임 126장. 한 장씩 보면 정지 이미지다.
- `comparison_preview.png`: Unity 비교 장면 정지 화면. 왼쪽은 리깅, 오른쪽은 PNG.

## Unity에서 비교

1. `Assets/Underwrite/AnimationPilot/Scenes/AnimationComparison.unity`를 연다.
2. Play를 누르면 왼쪽 리깅과 오른쪽 PNG가 같은 동작을 4초마다 함께 바꾼다.
3. Hierarchy의 `Comparison Controls`를 선택한다. `Auto Cycle`을 끄고 `Action Index`를 0~5로 바꾸면 특정 동작을 볼 수 있다. `Playback Speed`로 함께 속도를 조절한다.
4. 동작 순서: 0 대기 / 1 제자리 걷기 / 2 초조 / 3 놀람 / 4 낙담 / 5 안도·감사.

## 수정 가능한 자료

- `Prefabs/Protagonist_Rig.prefab`: 머리·몸통·골반·상하팔·상하 다리·장부·주머니가 분리된 관절 계층.
- `Clips/Rig/`: 여섯 개의 수정 가능한 AnimationClip. 관절 회전·위치와 표정 교체를 Animation 창에서 수정한다.
- `Prefabs/Protagonist_PNG.prefab`, `Clips/Frames/`: 같은 동작을 PNG 교체로 재생하는 버전.
- `Assets/Underwrite/Art/Parts/`: 투명 원본 파츠 시트, 안도 표정, Unity가 관리하는 분할·피벗 정보.
- `Assets/Underwrite/Editor/ComparisonBuilder.cs`: 연결된 편집기에서 명시적으로 실행하는 생성·출력 도구. 자동 실행하지 않는다.

수정 후 다시 출력하려면 `ComparisonBuilder.RunAll()`을 편집기에서 실행한다. 이 기능은 생성기가 관리하는 비교 장면·클립·컨트롤러·프리팹·프레임을 다시 만들므로, 수동 수정본은 별도 이름으로 저장해 둔다. 스프라이트 분할은 `work/parts_layout.json`, `work/relief_layout.json`을 읽는다.

## 비교의 의미와 범위

이번 결과는 **주인공 정면 한 방향의 여섯 동작을 비교하기 위한 시제품**이다. 리깅은 파츠를 관절로 움직이는 컷아웃 방식이다. SpriteSkin 메시 가중치로 피부를 연속 변형하는 리깅은 이번 샘플에 포함하지 않았다. 관절 부근의 옷 주름과 큰 자세 변화에는 추가 원화·보정이 필요하다.

PNG는 이 리깅을 12fps로 출력했다. 리깅은 실제 화면 갱신 속도로 보간되며 PNG는 정해진 프레임을 재생하므로 부드러움과 확대 시 선명도를 비교할 수 있다. 손으로 프레임마다 새로 그린 방식의 화풍 차이를 비교한 자료는 아니다.

모든 PNG는 512×640, 같은 캔버스와 원점, 투명 배경이다. 정면 제자리 걷기이며 월드 이동이나 8방향 전환 코드는 포함하지 않았다. 여섯 인물의 8방향 원화는 `Outputs/DirectionArt`에 따로 있다. 원화는 회전 설계 초안이고 바로 재생 가능한 8방향 스프라이트가 아니다.

## 검증 기록

프레임 수·투명도·캔버스·가장자리 잘림·각 동작의 실제 이미지 변화를 검사한다. 결과는 `frame_validation.json`에 저장한다. Unity 컴파일 및 Play 모드 재생은 별도로 확인하고 `unity_validation.json`에 기록한다.
