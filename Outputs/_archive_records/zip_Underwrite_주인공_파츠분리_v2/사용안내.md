# 주인공 정면 파츠 분리 v2

2026-10-15 / 기준: `주인공_정면_기준원화_v1.png`

기준 원화를 참조해 내장 이미지 도구로 파츠 원화를 재구성하고, Unity Sprite Editor 데이터 제공 API로 7개 스프라이트를 분할·PNG 출력했다. 원본 픽셀을 그대로 잘라 낸 분할과는 차이가 있으므로, 조립 시 얼굴과 비율을 원화에 대조해야 한다.

## 파일 구성

| PNG | 내용 |
|---|---|
| `parts/01_head_neck.png` | 머리와 목 |
| `parts/02_torso_pelvis.png` | 셔츠·조끼·벨트·골반이 이어진 몸통 |
| `parts/03_arm_R.png` | 캐릭터의 오른팔 전체와 손, 정면에서 화면 왼쪽 |
| `parts/04_arm_L.png` | 캐릭터의 왼팔 전체와 손, 정면에서 화면 오른쪽 |
| `parts/05_leg_R.png` | 캐릭터의 오른쪽 바지 다리와 신발 |
| `parts/06_leg_L.png` | 캐릭터의 왼쪽 바지 다리와 신발 |
| `parts/07_coin_pouch.png` | 캐릭터 왼쪽 허리에 달리는 주머니 |

`주인공_7파츠_원화_v2.png`는 전체 파츠 시트, `reference_master.png`는 비교용 기준 원화다. `parts_manifest.json`에 아틀라스 좌표·PNG 크기·초기 피벗을 기록했다. `제작_프롬프트.json`에 실제 사용한 프롬프트를 저장했다.

## 조립 방식

팔과 다리는 각각 하나의 연속된 그림이다. 내부의 뼈와 메시 가중치로 팔꿈치·무릎을 굽히는 용도이며, 별도의 상완·하완이나 허벅지·정강이 그림을 회전시키는 구조가 아니다. 몸통과 골반도 같은 파츠로 연결했다.

몸통의 팔 구멍 뒤로 팔 뿌리를, 골반 뒤로 다리 뿌리를, 셔츠 칼라 뒤로 목을 겹쳐 배치한다. 주머니는 몸통 앞에 둔다. 파일에 설정한 피벗은 분리 작업의 시작점이며, 실제 관절 위치와 가중치는 조립한 정지 자세에서 검증해야 한다. 목·어깨·고관절의 겹침 및 추가 작화 보정은 조립 검수 단계에서 확정한다.
