# 여섯 인물의 8방향 원화 초안

2026-10-15 / 내장 이미지 생성 도구로 제작. 사용한 전체 프롬프트는 `제작_프롬프트.json`에 기록했다.

주인공, 인간 남성, 인간 여성, 엘프 여성, 워리어 남성, 페어리 여성의 방향별 의상·머리·소품을 검토하는 자료다. 각 이미지에 여덟 시점을 배치했다. 큰 원화의 얼굴과 의상을 유지하는 데 중점을 두었으며, 필드 SD 비율과 픽셀 단위 기준점은 별도 제작 단계에서 통일해야 한다.

배치 목표는 위 줄 정면·전좌·좌측·후좌 / 아래 줄 후면·후우·우측·전우다. 생성 원화의 일부 대각선은 몸통 회전이 얕고 좌우 소품에 작은 불일치가 있어, 방향 키에 그대로 배정하거나 반전 복사하기 전에 정리가 필요하다. 책·가방·검·날개와 긴 머리의 가려지는 부분을 회전 설계 자료로 활용한다.

키 기준: 워리어 > 엘프 = 인간 남성 > 인간 여성 > 페어리. 각 종이는 화면을 채우도록 그려졌으므로 종이 안의 크기를 서로 비교해 키를 결정하지 않는다. 인간 여성은 작은 키와 가는 체형, 엘프는 긴 머리와 작은 뾰족 귀, 페어리는 둥근 사람 귀를 유지한다. 인물의 이름과 세부 성격은 아직 가칭/제안 단계다.

이 자료는 완성 애니메이션이나 분리 레이어 원본이 아니다. 실기용 파츠와 실제 움직임의 비교는 `Assets/Underwrite/AnimationPilot`의 주인공 정면 시제품에서 확인한다.
