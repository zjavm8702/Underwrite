# 주인공 환호 8방향 확장 시안

기존 정면(S)을 유지하고 SE/E/NE/N/NW/W/SW 각각8프레임, 총56장을 추가한다. 전체는8방향64장이다.

- 게임용 PNG: `Assets/Images/Characters/Protagonist/Cheer/{방향}/cheer_{방향소문자}_{00..07}.png`.
- 공통 캔버스512×960, 발밑 y947, 권장 피봇 하단 좌표(256,13). 기존 정면과 동일한 PPU를 사용한다.
- 공통 동작 순서: 준비 → 두 주먹을 갈비뼈 높이로 → 무릎을 살짝 굽히며 힘 모으기 → 어깨 높이로 주먹 올리기 → 양팔 V자 환호 → 머리 옆으로 팔 당기기 → 갈비뼈 높이로 내리기 → 정리.
- 시간240/120/120/120/300/180/180/300ms, 총1.56초, 게임에서는 일회 재생. 미리보기만 반복.
- 기본 제공 image_gen 사용. 정면 환호 시트는 동작 참조, 각 방향 Idle은 시점·복장 참조다. generation_prompts.json에 전체 프롬프트와 원본 경로를 기록한다. 각 방향source.png에 생성 원본을 보관한다.
- 후처리는 알파32 미만·분리 잡점 제거, 완성 인물 동일 비율 축소, 발 기준 정렬 및 분할·미리보기 출력이다. 방향 안에서는 프레임별로 별도 확대축소하지 않는다.
- 기존 정면 PNG와 기존 캐릭터 .meta의 해시를 보존한다. 새 PNG의 Unity 자동 임포트 메타가 생길 수 있으나 기존 메타를 직접 편집하지 않는다. Animator/Clip/Sprite Library 연결은 변경하지 않는다.
- 프레임별 세부 주름·실루엣에는 생성 원화의 미세한 차이가 남은 시안이다. 검사 결과는 verification.json, 원본좌표·배율은 staging.json, 기존 메타·정면 PNG 기준 해시는 before.json을 따른다.
