## 구도와 검수

수평선 없는 높은 사선 시점으로 지면이 넓게 보이고 지붕과 건물 정면이 함께 보인다. 여관은 왼쪽 위, 석조 기록실은 오른쪽 위, 지붕 달린 게시대와 좌판은 아래 가운데에 있다. 모두 아래쪽 입구와 접근 공간을 확보했다. 낮 빛, 술통·야외 탁자·따뜻한 창빛, 높은 창·봉인 게시, 빈 종이들로 장소를 구별했다. 사람·동물·읽히는 문자·큰 바닥 문양 없음. 네 가장자리는 담·울타리·수목으로 닫혔다. 전체 지도에서 목적 건물 잘림 없음. 검수용 카메라 크롭의 건물 잘림은 스크롤 창의 의도된 일부 표시다.

세 카메라 합성을 육안 확인했다. 첫 생성본에서 커 보인 시설·소품을 image_gen으로 축소 수정한 두 번째 생성본을 납품본으로 채택했다. 기존 배경과 같은 목재·석재·붉은기와 계열이며 낮 장면은 기존 실내보다 밝다. 최종 배경에는 합성 인물이 없다.

- 알파255: 8,294,400픽셀 전부. 연결 성분1, 분리 성분0, 숨은RGB0.
- 전체 화면 배경의 사방 접촉은 의도된 full-bleed. 투명 테두리·의도하지 않은 캔버스 프레임 없음.
- 통행 표시: 4,583,476px / 55.2599%, 4방향 연결 성분1개. 세 검수 앵커가 모두 같은 성분에 있음.
- 정적 배경으로 8방향·프레임 시퀀스·반복/일회·총재생시간은 해당 없음.

## 생성과 처리

기본 제공 image_gen 2회(새 배경 생성1, 크기 수정1), CLI/API fallback 미사용. generation_prompts.json에 전체 프롬프트. 첫 호출의 화풍 참조는 대화에 직접 표시한 GatherPlaces 세 이미지이며 파일 인자를 전달하지 않았다. 두 번째 호출은 첫 생성 원본 파일을 참조했다. 두 원본은 source/에 보존. 각1672×941 원본에서 선택본 전체를 크롭 없이 bilinear 보간 확대하여 3840×2160 RGBA8로 저장했다. 새 원화를 코드 변형으로 대체하지 않았다. 코드 처리는 해상도·PNG 채널 저장·검수 합성·수동 영역 표시·측정에 한정했다.

## 미해결·주의

- 사용자 시각 승인 전 시안이다. 네이티브4K 생성이 아니므로 확대에 따른 부드러움이 남는다.
- 판석은 불규칙하며 사람135px 기준 세로 약3~4단이 보인다. 요청의 두 장 남짓 기준과 차이가 남아 있다.
- 통행 표시는 그림 검토용이다. 지붕/수관 투영까지 제외하며 실제 발밑 충돌과 일치하지 않는다.
- 메타 목록에 외부 추가·삭제가 관측되어 전체 무변동은 확인하지 못했다.
- 상시 지시서의 일반 Assets 납품 규칙 대신 이번 명시 요청의 Outputs만 납품을 적용했다. 캐릭터 애니메이션 자동연결 규칙은 정적 배경에 적용하지 않는다.
