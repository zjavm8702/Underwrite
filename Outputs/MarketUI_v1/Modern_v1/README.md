# Market UI v1 — UI Toolkit 전달용 시안

상태: 사용자 승인 전 **시안**. 범위: 자료조사+PNG+설계 기록. 프로젝트 코드/Unity 연결 변경 없음.

1단계: [조사 원칙](../../MarketUI_Research_v1/README.md). 1단계 기록을 먼저 작성한 뒤 이미지 생성에 착수했다. 최신 문서와 실제 시장 코드를 읽었다. 기존 before.json만 있던 작업 폴더는 유지하고 이번 시점의 보존 기준은 before_current.json으로 별도 기록한다.

PNG는 한 장을 게임 배경으로 붙이라는 뜻이 아니다. Claude Code가 텍스트와 패널을 UI Toolkit 요소로 재구성할 때의 시각 참고다. 화면/조각 모두 불투명 판형. 캐릭터의 투명 실루엣/발밑 피봇 규칙은 해당 없음. 좌상단을 레이아웃 원점으로 사용한다. Outputs 밖 Assets 경로는 이번 요청에 지정되지 않아 추가하지 않는다.

## 정보 기록의 두 축

카드 첫 줄은 공개 여부(잠금+보라 면+4px 왼쪽 선+문구 / 공개는 중성색 문구), 둘째 줄은 출처·출처 성격·틱·대상 종목이다. 그 다음 제목, 펼친 본문 순서. 시장 공개와 신뢰도가 높음은 같은 의미가 아니다. 나만 아는 정보도 오보일 수 있고 공개 정보도 소문일 수 있다. '시장에 미공개'는 가격 반영 전인 정보의 범위를 뜻하며 수익을 보장하지 않는다.

| 출처 | 보조 문구 제안 | 주의 |
|---|---|---|
|길드 기록|기록 근거|상대적으로 신뢰 가능한 기록,진실 판정 아이콘 금지|
|사적 서신|직접 전언|접근 범위와 진실은 별개|
|여관 소문|전언 · 재확인 필요|오보 가능성|
|시장 게시판|공개 게시 · 내용 확인 필요|공개=참 금지|
|중개인 누설|재확인 필요|출처 신뢰 낮음.반드시 문구로 읽힘|

이 문구들은 Source enum에 따른 UI 설명 제안이지 코어 신뢰도 수치가 아니다. TruthOnly/TrueValue/TargetPrice/미래 일정은 표시하지 않는다. 정보 필터는 전체/나만 아는 정보/시장에 공개됨, 선택 종목 필터는 별도. 시안은 전체 종목 피드여서 브란/블랙무어 카드도 종목명을 반드시 쓴다.

## 차트·수치의 연결

SessionChangeRatio=(Price−SessionOpenPrice)/SessionOpenPrice. '장 시작 대비'를 표시하며 전일 대비라고 바꾸지 않는다. PriceHistory는 원가격의 꺾은선이고 OHLC/거래량 데이터는 없다.0~96틱이 공통 X축이며 시작점 포함 최대97관측점을 그릴 수 있다. 현재34틱이면 이후62틱 영역은 빈칸이다. 미래 사건이나 예상 가격 경로를 그리지 않는다. 시작가42와 현재56이면+33.3%. 관측값이1개면 점+기록 수집 중,변화가0이면 수평선. 세션 경계와240개 버퍼는 데이터 담당자가 식별해야 하며 현 API만으로 이전 세션 전체를 당일 차트라 부르지 않는다.

표시용 예시 상태(실행 캡처가 아님): 셀라56.0/2주/평단42,브란126.0/1주/평단120,블랙무어72.0/1주/평단66. 현금230+평가액292=총자산522, 실현손익0. 시작현금500에서 매입270인 예시 장부. 가격 궤적은 미실행 설계 예시이며 실제 RNG 결과가 아니다.

시장가: impact=Price×0.9×quantity/Liquidity, fill=max(PRICE_FLOOR,Price+impact/2), amount=fill×quantity. 셀라56/수량2/유동성60의 매수라면56.84,합계113.68 → 표시56.8/113.7. 매도는 impact 음수. 코어가 최종 판단하며 체결 Receipt.FillPrice/TotalAmount로 결과 표시. 실현손익은0에서 색 없이0, 양수는▲+빨강, 음수는▼−파랑.

시장 분위기는 코어enum의 평온/투자 열풍/공포/자금 부족 중1개만 표시. 상승/하락과 같은 색 배경으로 큰 패널을 칠하지 않는다. 사용자가 장세를 바꾸는 버튼이 아니다.

## 모션 규격(구현 제안)

가격 즉시 교체+배경 강조160ms,패널 전환180ms,버튼 눌림80ms.숫자 롤링/오버슈트/차트 미래보간 없음.16배에서는 표시 최대4Hz로 병합하고모든실제틱은계산한다.감소모션이면즉시교체.정보읽는동안자동스크롤금지,상단에새정보N건 버튼.성공메시지는사용자확인/다음주문까지유지.모션은PNG로재생확인하지않았고토스실측수치가아니다.

## 최종 내보내기·동시 작업 보존

이번 작업 정본은 Modern_v1/의8개 납품 PNG와 이 README다. 작업 도중 상위 MarketUI_v1/에 별도 시안 MarketUI_*.png, originals/, 다른 README가 추가되어 충돌을 피하려고 이번 결과를 이 하위 폴더에 복사했다. 상위의 다른 작업 기록·이미지는 삭제하거나 본 작업 결과로 집계하지 않았다. 원래 before.json도 보존했다. 본 폴더 before.json은이번시점 before_current.json의사본이다.

내보내기는 생성 원본1672×941을 요청 규격1920×1080 RGBA로 변환한 뒤 조각 보드만 사분면960×540으로 분리했다. 내용 수정은 imagegen으로 수행했고 변환/분리는 이미지 내용의 재작화가 아니다. PNG의 화면·조각은 모두 불투명 UI 참고 판형이다.

시안에서 남은 차이: 생성 PNG에는 미세한 면 명암이 있고 휴장판 일부 선택 컨트롤에 보라 강조가 남아 있다. 구현은 이 README의 단색 HEX와 중성색 선택 규칙을 따른다. 화면별 카드 크기·글꼴은 생성물의 시각 근사이며표의 px를측정치로 오인하지 않는다. 휴장 그림의 이전 장 선은48틱까지 보존된 예시 이력이다. 개장판 정보 카드 배치는 비공개 우선 강조 예시이며 실제 기록은 Tick 내림차순, 비공개는고정 강조/필터로 접근하도록 권장한다. 본 작업은 시안 납품이며 사용자 승인·실제 UI Toolkit 구현·모션 재생 검증은남아 있다.
